## 🏛️ 1. Shell (Kabuk) Nedir & Neden Kullanılır?

> **Mavi Takım Notu:** Grafik kullanıcı arayüzleri (_GUI_) sezgiseldir ancak arka planda devasa sistem kaynakları tüketirler. Komut Satırı ve **Shell (Kabuk)** ise sistem çekirdeği (_Kernel_) ile kullanıcı arasında doğrudan bir aracı ve kolaylaştırıcı (_facilitator_) rolü üstlenen komut dilidir.

- **Siber Güvenlik Avantajları:** Sunucularda RAM ve CPU yükünü minimumda tutar, yavaş ve kısıtlı ağ bağlantılarında bile jilet gibi çalışır ve en önemlisi kurumsal ağlarda log filtreleme ve operasyonel görevleri otomatize etmemizi sağlar.
    
- **Mevcut Kabuğu Öğrenme:** Terminalde o an hangi kabuk motorunu kullandığınızı görmek için şu komut koşturulur:
    
    Bash
    
    ```
    echo $SHELL  # Örn: /bin/bash
    ```
    
- **Sistemdeki Kabuklar listesi:** İşletim sisteminde yüklü olan tüm geçerli kabukların listesi adli olarak **`/etc/shells`** dosyasında saklanır (`cat /etc/shells`).
    

## 🛰️ 2. Linux Shell Çeşitleri ve Karşılaştırma Matrisi

Siber güvenlik analistlerinin kurumsal sıkılaştırma veya terminal esnekliği için tercih ettiği global kabuk motorları:

|Özellik Yapısı|Bash _(Bourne Again Shell)_|Fish _(Friendly Interactive)_|Zsh _(Z Shell)_|
|---|---|---|---|
|**Sektörel Standart**|De facto varsayılandır, en yaygın olanıdır.|Kullanıcı konforu ve kolaylığı odaklıdır.|Gelişmiş özelleştirme ve eklenti (plugin) dostudur.|
|**Syntax Highlighting**|Yerleşik olarak **yoktur** (Düz metin basar).|**Kutudan çıktığı gibi yerleşik gelir.**|Oh-My-Zsh gibi eklentilerle kurulabilir.|
|**Auto Spell (Düzeltme)**|**Yerleşik olarak yoktur.**|Yazım hatasını otomatik tamamlar.|Akıllı öneri ve imla düzeltme sunur.|
|**Komut Geçmişi**|`history` komutu ile oturum kayıtlarını döker.|Geçmişe göre canlı satır içi öneri yapar.|Gelişmiş sekmeli tamamlama sunar.|

- 💡 **Kalıcı Kabuk Değiştirme:** Terminal oturumunu varsayılan olarak Zsh kabuğuna kalıcı olarak sabitlemek için şu komut tetiklenir:
    
    Bash
    
    ```
    chsh -s /usr/bin/zsh
    ```
    

## 🛠️ 3. Shell Scripting Yapı Taşları (Script Anatomy)

Siber güvenlikte süreçleri, taramaları veya log ayrıştırma adımlarını otomatize etmek için birden fazla Linux komutunun tek bir yürütülebilir dosyada birleştirilmesine **Shell Scripting** denir.

### A) Shebang (`#!`) [Yorumlayıcı Kilidi]

Script dosyasının istisnasız en üstündeki ilk satırdır. Sisteme bu dosyanın içerisindeki komutların hangi kabuk motoru ile yorumlanacağını söyler.

Bash

```
#!/bin/bash
```

### B) Değişkenler (Variables) & Kullanıcı Girdisi (`read`)

Verileri dinamik olarak RAM hafızasında tutar. Ekrana çıktı basmak için `echo`, kullanıcıdan interaktif klavye girdisi toplamak için `read` kullanılır. Değişken çağrılırken başına **`$`** sembolü eklenir.

Bash

```
echo "Lütfen adınızı girin:"
read name
echo "Hoş geldin, $name"
```

### C) Loops (Tekrarlı Döngüler)

Aynı siber güvenlik görevini veya tarama işlemini belirli parametreler bitene kadar tekrarlayan (_iterative tasks_) yapılardır.

Bash

```
for i in {1..10}; do
    echo "Analiz edilen satır: $i"
done
```

### D) Conditional Statements (Koşullu İfadeler)

Mantıksal şartlar sunar. Şart `if` ile başlar, tersi olan **`fi`** kelimesi ile kapatılır.

Bash

```
if [ "$name" = "Stewart" ]; then
        echo "Yetki Onaylandı. Gizli Flag: THM_Script"
else
        echo "Yetkisiz Erişim Reddedildi!"
fi
```

### E) Yorum Satırları (Comments)

Kodların arasına analistin kendisi için düştüğü, sistemin çalıştırmayıp atladığı notlardır. Satır başına **`#`** işareti konur.

- 🚨 **Kritik Çalıştırma Refleksi:** Yeni yazılan bir script dosyası Linux'ta korumalıdır. Dosyaya executable (çalıştırılabilir) izin yetkisi atamak için **`chmod +x script.sh`** komutu şarttır. Çalıştırırken de sistem yollarında boğulmamak adına o anki dizini işaret eden **`./script.sh`** kalıbı kullanılır.

- _Lab Bulgusu / Doğru Kimlik Doğrulama PIN'i:_ **`7385`**
    

### Vaka B: Adli Log Taraması & Flag Avcılığı (`flag_hunt.sh`)

Sistemde şüpheli bir izi sürmek için `sudo su` komutuyla en üst yetkili **root** kullanıcısına yükselinmiş ve `/var/log` dizini altındaki tüm `.log` uzantılı dosyalar içinde `thm-flag01-script` kelimesini otomatik arayan bir döngü scripti koşturulur:

Bash

```
# Arka planda sessizce kelime tarayan if-grep mimarisi
if grep -q "$flag" "$file"; then
     echo "Flag found in: $(basename "$file")"
fi
```

- 🚨 **Adli Analiz Bulgusu:** Aranan sinsi anahtar kelimenin içerisinden çıktığı o şüpheli log dosyasının adı: **`authentication.log`**
    
- **Log İçeriği Soru Cevabı:** `grep "cat" /var/log/authentication.log` komutuyla dosyanın en altında tespit edilen o gizli kedinin uyuduğu yer: **`under the table`** _(masanın altında)._
