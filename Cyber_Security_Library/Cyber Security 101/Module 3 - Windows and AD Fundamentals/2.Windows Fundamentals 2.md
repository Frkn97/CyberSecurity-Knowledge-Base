## ⚙️ 1. System Configuration (MSConfig)

> **Mavi Takım Notu:** Bu araç temelde sistemin başlangıç (_Startup_) ve boot problemlerini çözmek, teşhis koymak için kullanılır. Bir SOC Analisti olarak içerideki **Tools** (Araçlar) sekmesini, Windows'un gizli araçlarını ve onların arka plandaki `.exe` isimlerini öğrenmek için bir el kitabı gibi kullanabilirsin.

- **Çalıştır Kodu:** `msconfig`
    
- **Ana Sekmeler:**
    
    - **General:** Sistemin nasıl açılacağını seçersin (Normal, Teşhis veya Seçmeli).
        
    - **Boot:** Güvenli mod (_Safe Boot_) gibi gelişmiş önyükleme ayarları yapılır.
        
    - **Services:** Arka planda dönen tüm servisleri (çalışan/duran) listeler.
        
    - **Startup:** Windows Server işletim sistemlerinde bu sekme boştur. Server sistemlerinde başlangıç uygulamalarını görmek için Çalıştır'a `shell:startup` yazarak başlangıç klasörüne gitmek gerekir.
        
    - **Tools:** Windows'un diğer tüm yönetimsel araçlarının listesi ve onları tetikleyen komutlar burada yer alır.
        
        - _Örnek Komut (Windows Troubleshooting):_ `C:\Windows\System32\control.exe /name Microsoft.Troubleshooting`
            
        - _Örnek Komut (Control Panel):_ `control.exe`
            

## 💻 2. Gelişmiş Sistem Ayarları & Crash Dump Analizi

> **Mavi Takım Notu:** Bir sistem siber saldırıya uğradığında veya çöktüğünde (Mavi Ekran - BSoD), arkasında **Crash Dump** (Hata Dökümü) dosyası bırakır. Adli bilişim (_Forensics_) analistleri bu dosyayı inceleyerek olayın kök nedenini bulur.

- **Erişim Yolu:** Arama Çubuğu ➡️ _Gelişmiş sistem ayarlarını görüntüle (View advanced system settings)_
    
- **Sanal Bellek (Page File):** Fiziksel RAM dolduğunda Windows'un sabit diski RAM gibi kullanmasıdır. Windows Fundamentals laboratuvarındaki varsayılan boyutu **1048 MB**'tır.
    
- **Hata Ayıklama Bilgisi Yazma (Crash Dump Tipleri):**
    
    1. Küçük bellek dökümü (_Small memory dump - 256 KB_)
        
    2. Çekirdek bellek dökümü (_Kernel memory dump_)
        
    3. Otomatik bellek dökümü (_Automatic memory dump_)
        
    4. Tam bellek dökümü (_Complete memory dump_)
        

## 🔒 3. User Account Control (UAC) Settings

> **Mavi Takım Notu:** Zararlı yazılımların (_Malware_) sistemde izinsiz yönetici yetkisi almasını engellemek için kurulan ilk savunma hattıdır. Kırmızı takım (saldırganlar) sisteme sızdığında ilk iş **UAC Bypass** teknikleri arar.

- **Çalıştır Kodu:** `UserAccountControlSettings.exe`
    
- **4 Güvenlik Seviyesi (Slider Konumları):**
    
    1. **Always Notify (Her zaman uyar):** En yüksek güvenlik. Kullanıcı işlem yaparken ekran kararır (_Secure Desktop_).
        
    2. **Notify for apps (Sadece uygulamalarda uyar):** Varsayılan ayar. Kullanıcı ayar değiştirirken uyarmaz, uygulamalarda uyarır.
        
    3. **Notify without dimming:** Uyarır ama ekranı karartmaz.
        
    4. **Never notify (Asla uyarma):** Güvenlik kapalıdır. Zararlılar arkada sessizce yetki yükseltebilir.
        

## 🛠️ 4. Computer Management (Bilgisayar Yönetimi)

> **Mavi Takım Notu:** Tüm yönetimsel araçları tek çatıda barındıran ana karargahtır. SOC analistlerinin yerel analizlerde en çok ziyaret ettiği konsollardan biridir.

- **Çalıştır Kodu:** `compmgmt.msc`
    
- **Kritik Alt Bölümler:**
    
    - **Task Scheduler (Görev Zamanlayıcı):** Belirli zamanlarda veya tetikleyicilerle çalışan otomatik görevlerdir.
        
        - 🚨 **Saldırgan Taktiği:** Saldırganlar sistemde kalıcı olmak için (_Persistence - TA0003_) buraya gizli zamanlanmış görevler eklerler.
            
        - _Lab Bulgusu:_ `GoogleUpdateTaskMachineUA` görevi her gün **`6:15 AM`** saatinde çalışmak üzere yapılandırılmıştır.
            
    - **Event Viewer (Olay Görüntüleyicisi):** Windows'un kara kutusudur. Log analizi için kalbidir. 5 ana olay tipi vardır: _Error, Warning, Information, Success Audit, Failure Audit._
        
    - **Shared Folders (Paylaşılan Klasörler):** Ağda paylaşılan dosyaları listeler. `C$` ve `ADMIN$` gibi sonunda dolar işareti olanlar Windows'un gizli/idari paylaşımlarıdır.
        
        - _Lab Bulgusu:_ Ağda paylaşılan gizli klasörün adı **`sh4r3dF0Ld3r`** olarak tespit edilmiştir.
            
    - **Disk Management (Disk Yönetimi):** Disk bölme, harf atama (E:) ve genişletme işlemlerine bakar.
        
    - **Services (Hizmetler):** Arka plan uygulamalarının yönetimidir. Başlangıç türleri: _Automatic, Manual, Disabled._
        
        - _Lab Bulgusu:_ Üreticisi (_Manufacturer_) "Systems Internals" olarak listelenen kritik servis: **`PsShutdown`**
            

## 📋 5. System Information (Sistem Bilgisi)

> **Mavi Takım Notu:** Saldırganın veya analistin içeri girdiğinde sistemin donanım mimarisini, işletim sistemi detaylarını, lisans bilgilerini ve Çevre Değişkenlerini (_Environment Variables_) tek ekranda gördüğü keşif (_Reconnaissance_) raporudur.

- **Çalıştır Kodu:** `msinfo32.exe`
    
- **Laboratuvar Kayıt Değerleri:**
    
    - **System Name:** `THM-WINFUN2`
        
    - **Windows License Registered To:** `Windows User`
        
    - **ComSpec Değişkeni Değeri:** `%SystemRoot%\system32\cmd.exe` _(Sistemin varsayılan komut satırı kabuk yolunu gösterir)._
        

## 📊 6. Resource Monitor (Kaynak İzleyicisi)

> **Mavi Takım Notu:** Görev yöneticisinin (_Task Manager_) çok daha gelişmiş versiyonudur. Canlı olarak hangi işlem (_Process_) ağda nereye bağlanıyor (Network), hangi dosyayı okuyor veya kilitliyor (_File Handle / Modules_) görmemizi sağlar. Anomali tespiti için hayati önem taşır.

- **Çalıştır Kodu:** `resmon.exe`
    
- **4 Ana İzleme Sekmesi:** CPU, Memory, Disk, Network.
    

## 🧾 7. Windows Registry (Kayıt Defteri)

> **Mavi Takım Notu:** Windows'un kalbidir; kullanıcı profilleri, donanım ayarları, portlar ve yüklenen tüm programların konfigürasyonları burada hiyerarşik bir veritabanı olarak tutulur. Saldırganlar virüsleri başlangıçta çalıştırmak için buraya yazar (_Run/RunOnce anahtarları_), mavi takım ise buradaki değişiklikleri (_Registry Monitoring_) loglardan izler.

- **Çalıştır Kodu:** `regedt32.exe` _(Alternatif olarak `regedit.exe` kullanılabilir)._
    

## 🎯 8. Komut Satırı (CMD) Can Simidi Kartı

> **Mavi Takım Notu:** Arayüzün olmadığı durumlarda (SSH veya Kırmızı Takımın elde ettiği Reverse Shell bağlantılarında) bilgi toplamak için bu komutlar analistin can suyudur.

- `hostname` ➡️ Bilgisayarın adını verir.
    
- `whoami` ➡️ O an hangi kullanıcı yetkisiyle sistemde olduğunu söyler.
    
- `ipconfig /all` ➡️ Ağ kartlarının tüm detaylı bilgilerini (MAC adresi, DNS, DHCP vb.) döker.
    
    - _Sistem Yapılandırma Karşılığı:_ `C:\Windows\System32\cmd.exe /k %windir%\system32\ipconfig.exe`
        
- `netstat` ➡️ Aktif TCP/IP ağ bağlantılarını ve açık portları listeler.
    
- `net help [komut]` ➡️ Net komutunun alt komutları için yardım menüsünü açar (Örn: `net help user`).
    
- `cls` ➡️ Terminal ekranını temizler.
    
- `/?` ➡️ Komutların yanına gelerek yardım kılavuzunu açar (Örn: `ipconfig /?`).
