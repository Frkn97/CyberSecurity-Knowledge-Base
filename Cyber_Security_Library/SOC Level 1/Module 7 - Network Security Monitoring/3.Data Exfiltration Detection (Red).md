## 🏛️ 1. Mimari Yapı ve Temel Mantık (Exfiltration Architecture)

Veri Sızıntısı (**Data Exfiltration**), bir saldırganın hedef kurum ağına sızdıktan sonra kritik ve hassas varlıkları (müşteri verileri, kaynak kodları, finansal tablolar, kimlik bilgileri) kurum dışındaki kontrol noktasına yetkisiz olarak aktarmasıdır. Cyber Kill Chain modelinde **"Actions on Objectives"** (Hedef Üzerinde Aksiyon) aşamasına karşılık gelir.

  

```
[ Ağ İçi Varlıklar ]                [ Hazırlık (Staging) ]             [ Gizli İletişim & Çıkış ]
 • Veritabanları (SQL)    ───────►   • Sıkıştırma (ZIP, RAR, 7z) ──────► • DNS Tünelleme (Port 53 UDP)
 • Dosya Sunucuları (SMB)            • Şifreleme (AES, RSA)              • HTTP/HTTPS POST (Port 80/443)
 • Uç Noktalar (Workstations)        • Kodlama (Base64, Hex)             • FTP/SFTP (Port 21 / Data Ports)
                                     • Steganografi (Resim/Ses içine)    • ICMP Echo Payload (Ping Tüneli)
```

### 🔹 Veri Sızıntısının 4 Temel Fazı

1. **Discovery / Collection (Keşif ve Toplama):** Saldırganın iç ağda hassas dosya ve veritabanlarını bulup toplaması.
    
      
    
2. **Staging / Compression (Hazırlık ve Sıkıştırma):** Verilerin tespit edilmesini zorlaştırmak amacıyla tek bir arşivde toplanması, `ZIP/7z/RAR` ile paketlenmesi veya `Base64` ile kodlanması.
    
      
    
3. **Exfiltration Transport (Aktarım):** Verinin ağ protokolleri, bulut servisleri veya harici ortamlar üzerinden dışarı sızdırılması.
    
      
    
4. **C2 Coordination (Komuta Kontrol Koordinasyonu):** Transferin zamanlamasını, parçalanmasını (chunking) yönetme ve alındı onayını kontrol etme.

## 🔍 4. Kanal Bazlı Sızıntı Mekanizmaları & Pratik İnceleme

```
[ 4 Temel Sızıntı Kanalı & Tespit Refleksleri ]
 ├── 1. DNS Tünelleme ──► Çok sayıda sorgu + TXT kayıtları + Uzun subdomain (>60-100 karakter)
 ├── 2. FTP Transferi  ──► Cleartext USER/PASS + STOR komutu + Büyük veri aktarımı (frame.len > 90)
 ├── 3. HTTP POST      ──► Dışa doğru yüksek `bytes_sent` + Anormal URI + HTTP POST gövdesi
 └── 4. ICMP Tüneli    ──► Anormal paket boyutu (frame.len > 100) + Tipik 64 byte yerine veri gömülmesi
```

### 🔹 Kanal 1: DNS Tünelleme (DNS Exfiltration)

DNS protokolü (`UDP 53`) hemen hemen tüm ağlarda dışarıya izinli olduğu için saldırganlar tarafından en sık istismar edilen kanallardan biridir. Saldırgan veriyi küçük parçalar halinde subdomain olarak kodlar (Örn: `[base64_data].tunnelcorp.net`).

  

#### Wireshark Filtreleri

Kod snippet'i

```
# Yalnızca DNS trafiğini izole etme
dns

# Yanıt dönmeyen sorguları filtreleme (saldırgan tek yönlü query ile exfil yapıyorsa)
dns.flags.response == 0

# Paket uzunluğu 70 byte'tan büyük DNS paketlerini yakalama (anormal subdomain uzunluğu)
dns && frame.len > 70

# Şüpheli alan adına göre sorguları daraltma
dns && dns.qry.name contains "tunnelcorp.net"
```

#### Splunk Sorguları

Splunk SPL

```
# DNS loglarında kaynak IP başına düşen sorgu sayısını bulma
index="data_exfil" sourcetype="DNS_logs" 
| stats count by src_ip

# En çok sorgulanan alan adlarını frekans analiziyle sıralama
index="data_exfil" sourcetype="DNS_logs" 
| stats count by query 
| sort - count

# Karakter uzunluğu 30'dan büyük olan sorguları filtreleme (Tünelleme Tespiti)
index="data_exfil" sourcetype="DNS_logs" 
| where len(query) > 30

# Şüpheli domain için oluşan toplam log hacmini sayma
index="data_exfil" sourcetype="DNS_logs" "tunnelcorp.net"
```

> [!NOTE]
> 
> **DNS Tünelleme İmzası:** Normal bir DNS sorgusu `google.com` gibi kısa ve bilinen köklerden oluşurken; DNS tünellemede `aW5pdGVjaC1zZWNyZXQ.tunnelcorp.net` şeklinde yüksek entropili, Base32/Base64/Hex kodlu uzun subdomainler peş peşe gönderilir.
> 
>   

### 🔹 Kanal 2: FTP ile Dosya Kaçırma (FTP Exfiltration)

FTP (`Port 21`) şifresiz bir protokoldür; kullanıcı adları, parolalar ve dosya yükleme komutları açık metin olarak yakalanabilir.

  

#### Wireshark Filtreleri

Kod snippet'i

```
# FTP kontrol ve veri trafiğini birlikte filtreleme
ftp || ftp-data

# Kimlik doğrulama isteklerini inceleme (Kullanıcı adı ve şifreler)
ftp.request.command == "USER" || ftp.request.command == "PASS"

# Belirli bir kullanıcı adını (örneğin guest) içeren oturumları arama
ftp.request.arg contains "guest"

# Dosya yükleme (STOR) komutlarını filtreleme
ftp contains "STOR"

# Belirli uzantıları (CSV, XLSX, PDF) içeren transferleri yakalama
ftp contains "csv"

# Yük taşıyan büyük boyutlu FTP kontrol/veri paketlerini tespit etme
ftp && frame.len > 90

# Ağ trafiğinde doğrudan THM bayrağını arama
ftp contains "THM"
```

> [!TIP]
> 
> **Adli Analiz Refleksi (TCP Stream Takibi):** Şüpheli bir FTP veya HTTP paketi yakaladığında Wireshark üzerinde pakete sağ tıklayıp **Follow $\rightarrow$ TCP Stream** demek, transfer edilen dosyanın tüm içeriğini ve konuşma geçmişini açık metin olarak okumanı sağlar.
> 
>   

### 🔹 Kanal 3: HTTP/HTTPS POST ile Sızıntı (HTTP Exfiltration)

Web trafiği yoğun olduğu için saldırganlar çaldıkları verileri meşru web sitelerine veya kendi C2 sunucularına `HTTP POST` isteğiyle gönderir.

  

#### Splunk Sorguları

Splunk SPL

```
# Yalnızca dışa doğru yapılan HTTP POST isteklerini listeleme
index="data_exfil" sourcetype="http_logs" method=POST

# Domain bazında gönderilen ortalama, en yüksek ve en düşük byte hacmini hesaplama
index="data_exfil" sourcetype="http_logs" method=POST 
| stats count avg(bytes_sent) max(bytes_sent) min(bytes_sent) by domain 
| sort - count

# 600 byte'tan büyük POST isteklerini tablo halinde dökme (Anomali Tespiti)
index="data_exfil" sourcetype="http_logs" method=POST bytes_sent > 600 
| table _time src_ip uri domain dst_ip bytes_sent 
| sort - bytes_sent
```

#### Wireshark Filtreleri

Kod snippet'i

```
# Yalnızca HTTP POST isteklerini filtreleme
http.request.method == "POST"

# Belirli bir boyuttan (örneğin 750 byte) büyük HTTP POST paketlerini izole etme
http.request.method == "POST" and frame.len > 750
```

### 🔹 Kanal 4: ICMP Tünelleme (Ping Exfiltration)

ICMP (`Type 8: Echo Request`, `Type 0: Echo Reply`), ağ teşhisi (ping) için tasarlanmıştır. Tipik bir ping paketi 32 ila 64 byte veri taşır (Windows varsayılanı 32 byte, Linux 56/64 byte). Saldırganlar dosya parçalarını bu veri gövdesine ekleyerek dışarı taşır.

  

#### Wireshark Filtreleri

Kod snippet'i

```
# Tüm ICMP paketlerini izole etme
icmp

# Yalnızca giden Echo Request (Ping isteği) paketlerini filtreleme
icmp.type == 8

# Paket boyutu 100 byte'tan büyük olan anormal ping isteklerini yakalama
icmp.type == 8 and frame.len > 100
```

> [!WARNING]
> 
> **ICMP Boyut Eşiği:** Normal şartlarda bir ICMP paketi toplam çerçeve uzunluğunda ~74 byte civarındadır. `frame.len > 100` filtresi uygulandığında paket dönüyorsa, o ping paketinin veri kısmına (`icmp.payload`) yabancı bir yük/veri enjekte edilmiş demektir.
> 
>

## 🚦 Tekrar Kategorisi & 3 Dakikalık Pazar Tekrar Stratejisi

### 🔴 Kırmızı Sınıf: Pratik, Filtreleme ve Anomali Eşik Değerleri

Bu oda **Kırmızı Sınıf**'tadır (Wireshark Display Filter & Splunk SPL ezberi, paket boyutu eşik değerleri).

  

### ⏱️ Pazar Günü 3 Dakikalık Hızlı Tekrar Rutini

1. **Paket Boyutu Eşik Değerlerini Hatırla (1. Dakika):**
    
      
    - _Normal ICMP Ping:_ ~74 byte $\rightarrow$ _Anomali:_ `icmp.type == 8 and frame.len > 100`
        
          
        
    - _Normal DNS Sorgusu:_ < 30 karakter $\rightarrow$ _Anomali:_ `len(query) > 30` veya `frame.len > 70`
        
          
        
    - _HTTP POST Sızıntısı:_ Dışa doğru tekil büyük aktarım $\rightarrow$ `bytes_sent > 600` veya `frame.len > 750`
        
          
        
2. **Kritik Wireshark Filtrelerini Zihninde Yaz (2. Dakika):**
    
      
    - FTP Dosya Yükleme: `ftp contains "STOR"`
        
          
        
    - FTP Kullanıcı Kontrolü: `ftp.request.command == "USER"`
        
          
        
    - DNS Tüneli: `dns && dns.qry.name contains "domain"`
        
          
        
3. **Mülakat Hikayesi (3. Dakika):**
    
    _"Saldırganlar veriyi dışarı kaçırırken yalnızca web trafiğini değil, güvenlik duvarlarının genellikle denetlemediği ICMP ve DNS gibi temel ağ teşhis protokollerini tünel olarak suistimal ederler. Bir L1 analisti olarak standart paket boyutu ve entropi sapmalarını tespit ederek bu tünelleri açığa çıkarırım."_
