# 🛡️ TryHackMe: The Greenholt Phish (SOC Level 1)

## 🏗️ Mimari Yapı ve Vaka İnceleme İş Akışı

Greenholt PLC şirketindeki bir satış yöneticisine gelen şüpheli e-postanın incelenmesi, gerçek bir SOC L1 triyaj senaryosunu simüle eder. Bir oltalama vakasını incelerken adli analiz şu 4 aşamalı hiyerarşik iş akışıyla yürütülür:

  

Plaintext

```
[ Gelen Şüpheli E-posta (challenge.eml) ]
       │
       ├──► 1. Sosyal Mühendislik & Gösterge Triyajı
       │         └─► Beklenmeyen Para Transferi, Genel Hitap ("Good day"), Talep Edilmemiş Ek
       │
       ├──► 2. Başlık (Header) & DNS Doğrulama Analizi
       │         ├─► Display Name vs. From vs. Reply-To Uyumsuzluğu
       │         ├─► Originating IP (Public vs. Private Hop Ayrımı) & WHOIS Sahiplik Tespiti
       │         └─► Return-Path Domaini Üzerinde SPF / DMARC Kayıt Taraması
       │
       ├──► 3. Gövde & Güvenli Ek Dosya Analizi (Attachment Triage)
       │         ├─► Eki İndirmeden MIME Base64 Çıkarma
       │         └─► Linux Pipe Hattı ile SHA-256 Özeti Hesaplama
       │
       └──► 4. Tehdit İstihbaratı ve İtibar Taraması (OSINT / VirusTotal)
                 ├─► Dosya Boyutu ve Gerçek Dosya Türü (MIME Magic Bytes) Kontrolü
                 └─► Çift Uzantı / Maskeleme Tespiti (CAB vs. RAR)
```

## 🔍 1. E-posta Başlık (Header) ve Ağ Ayrıştırması

E-posta analizi sırasında Thunderbird ile açılan `challenge.eml` dosyasında `Ctrl + U` (`View -> Message Source`) kısayolu ile kaynak kod görüntülenir.

> 
>   
> 
> - **Konu (Subject):** Para transferi referans numarası içerir (`09674321`).
>     
>       
>     
> - **Görünen İsim (Display Name):** `Mr. James Jackson`
>     
>       
>     
> - **Gönderici Adresi (From):** `info@mutawamarine.com`
>

### Kaynak IP ve Hop Analizi (Originating IP vs. Internal Relays)

Başlıktaki `Received:` satırları tersten okunarak iletinin internete ilk çıktığı genel IP adresi tespit edilir:

  

Plaintext

```
Received: from 10.197.41.148 (EHLO sub.redacted.com) by mta4212.mail.bf1.yahoo.com with SMTP;
Received: from [192.119.71.157] by ...
```

> [!warning] SOC Analist Uyarısı (Private IP vs Public IP)
> 
> `10.197.41.148` adresi RFC 1918 standardına göre Class A Özel Ağ (Private IP) bloğuna aittir ve Yahoo'nun kendi veri merkezi içi dahili aktarımını (Internal Relay) temsil eder. E-postayı gönderen saldırganın gerçek **Originating IP adresi `192.119.71.157`**'dir.
> 
>   

## 🌐 2. OSINT ve DNS Kayıt Taraması (SPF / DMARC / WHOIS)

Saldırgan IP adresinin ve kullanılan alan adının kimlik doğrulama politikalarını denetlemek için harici araçlar ve DNS sorguları uygulanır:

  

Bash

```
# Gönderici IP adresinin sahipliğini ve ISP bilgisini sorgulama
whois 192.119.71.157
```

- **IP Sahibi (Owner):** HostPapa (veya Hostwinds LLC kayıt havuzu).
    
      
    
- **Return-Path Domaini:** `mutawamarine.com`
    
      
    

> [!check] Alan Adı Güvenlik Kayıtları
> 
>   
> 
> - **SPF Kaydı (dmarcian SPF Surveyor):**
>     
>     `v=spf1 include:spf.protection.outlook.com -all`
>     
>     _E-posta başlığında **SPF fail** dönmüştür; çünkü `192.119.71.157` IP adresi Microsoft 365 (`spf.protection.outlook.com`) yetkili sunucu havuzunda yer almamaktadır._
>     
>       
>     
> - **DMARC Kaydı (dmarcian Domain Checker):**
>     
>     `v=DMARC1; p=quarantine; fo=1`
>     
>     _`p=quarantine` politikası, SPF/DKIM uyumsuzluğunda postanın karantinaya/spama alınmasını emreder. `fo=1` parametresi ise SPF veya DKIM kontrollerinden herhangi biri başarısız olduğunda adli rapor üretilmesini sağlar._
>     
>       
>     

## 🔬 3. Ek Dosya Güvenli Ayrıştırma ve SHA-256 Hash Alma

Zararlı bir eki diske indirmeden, metin tabanlı `.eml` dosyası içindeki Base64 bloğunu Linux boru hattı (pipe) ile doğrudan hashleme yöntemidir:

  

Bash

```
# 1. Adım: E-posta kaynak kodundaki Base64 bloğu bir metin dosyasına yazılır
echo "<Base64_Karakter_Dizisi>" > base64.txt

# 2. Adım: Base64 çözülerek bellekte doğrudan SHA256 özetine yönlendirilir (Diske yazmadan!)
cat base64.txt | base64 --decode | sha256sum
```

- `cat base64.txt`: Base64 dizesini okur.
    
      
    
- `base64 --decode` (veya `base64 -d`): Metinsel veriyi ikili (binary) ham veriye çözer.
    
      
    
- `sha256sum`: Çıkan ikili akışın SHA-256 kriptografik parmak izini hesaplar.
    
      
    
- **Üretilen SHA-256 Hash:** `2e91c533615a9bb8929ac4bb76707b2444597ce063d84a4b33525e25074fff3f`
    
      
    

> [!danger] Ek Dosya Detayları (VirusTotal Analizi)
> 
>   
> 
> - **Görünen Ek Adı:** `SWT_#09674321____PDF__.CAB` (Kullanıcıyı kandırmak için isme PDF ve `.CAB` sıkıştırma uzantısı eklenmiştir).
>     
>       
>     
> - **Dosya Boyutu:** 400.26 KB
>     
>       
>     
> - **Gerçek Dosya Türü (True File Type):** RAR (Sıkıştırılmış arşiv dosyası).
>     
>
