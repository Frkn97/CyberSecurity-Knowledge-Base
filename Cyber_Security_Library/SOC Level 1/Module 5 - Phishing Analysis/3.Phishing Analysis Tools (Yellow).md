# 🛡️ TryHackMe: Phishing Analysis Tools (SOC Level 1)

## 🏗️ Mimari Yapı ve Otomasyon Mekanizması

L1 SOC Analisti için oltalama (phishing) analizi süreci; ham e-postadan toplanan artefaktların (IP, domain, URL, dosya hash'i) merkezi güvenlik araçları, itibar servisleri ve dinamik sandbox ortamları kullanılarak triyaj edilmesini ve vakanın çözümlenmesini (Case Resolution) kapsar.

  

```
[ Şüpheli E-posta (.eml / .msg) ]
       │
       ├──► 1. Başlık Analiz Araçları (MHA, Google Admin Toolbox, Mailheader.org)
       │         └─► Sender IP, Return-Path, SPF/DKIM/DMARC Doğrulaması
       │
       ├──► 2. URL & Domain İtibar Kontrolü (URLScan.io, Talos, IPinfo, CyberChef)
       │         └─► Obfuscated/Kısaltılmış Link Açma, Ekran Görüntüsü, DOM/Script Analizi
       │
       ├──► 3. Ek Dosya Statik Analizi (sha256sum, VirusTotal, Cisco Talos File Rep.)
       │         └─► SHA256 Çıkarma, Anti-Virüs Motor Taraması, Strings Analizi
       │
       ├──► 4. Dinamik Sandbox Patlatma (ANY.RUN, Hybrid Analysis, Joe Sandbox)
       │         └─► Gerçek Zamanlı Davranış, Süreç Ağacı, Ağ Bağlantıları, CVE Tespiti
       │
       └──► 5. Uçtan Uca SOC Otomasyonu (PhishTool)
                 └─► Vaka Çözümü, Sınıflandırma (Whaling, Credential Harvesting), IoC Çıkarma
```

### Temel İletişim Ajanları

- **MUA (Mail User Agent):** Kullanıcının e-postaları okuduğu ve yönettiği istemcidir (Thunderbird, Outlook, Gmail web arayüzü).
    
      
    
- **MTA (Message Transfer Agent):** E-postaları sunucular arasında ileten ve yönlendiren arka plan posta sunucusudur (Postfix, Exim, Sendmail).
    
      
    

## 🗂️ 1. Toplanması Gereken Temel Artefaktlar (Checklist)

Bir analistin inceleme başlatırken yapılandırılmış olarak toplaması gereken veriler iki ana gruba ayrılır:

  

|**Bölge**|**Toplanacak Artefakt**|**SOC Amacı ve Açıklama**|
|---|---|---|
|**Header (Başlık)**|**Sender Email Address**|Gönderen e-posta adresi (Envelope vs. Header kontrolü).|
|**Header (Başlık)**|**Sender IP & Reverse DNS**|E-postanın çıktığı ilk genel IP ve PTR kayıt sorgusu.|
|**Header (Başlık)**|**Subject Line**|Sosyal mühendislik ve yapay aciliyet (Urgency) tespiti.|
|**Header (Başlık)**|**Recipient Address**|Hedef kullanıcı; To/CC veya toplu gizleme için **BCC** kontrolü.|
|**Header (Başlık)**|**Reply-To / Return-Path**|Cevabın veya hata bildiriminin yönlendirildiği şüpheli adres.|
|**Header (Başlık)**|**Date & Timestamp**|İletim gecikmelerini ve kampanya zamanlamasını belirleme.|
|**Body (Gövde)**|**URLs & Hyperlinks**|Kısaltılmış/gizlenmiş linklerin gerçek hedef adresleri.|
|**Body (Gövde)**|**Attachment Name & Ext**|Çift uzantılı veya riskli formatlar (`.dot`, `.xlsx`, `.zip`).|
|**Body (Gövde)**|**Attachment Hash**|Tehdit istihbaratı sorguları için **SHA256** veya **MD5** değeri.|

> [!TIP]
> 
> **Artefakt Ayrıştırma Sıralaması:**
> 
> Analize her zaman en üst seviye meta veriden (Header) başla $\rightarrow$ Ardından gövdedeki URL ve yönlendirmeleri izole araçlarla çek $\rightarrow$ En son ek dosyaların hash değerini diske indirmeden veya izole sandbox'ta hesapla.
> 
>

## 💻 3. Komutlar ve Canlı Terminal Kullanımları

### Linux SHA256 Hash Alma Komutu

Şüpheli bir ek dosyanın hash değerini üretmek ve istihbarat servislerinde sorgulamak için kullanılır:

  

Bash

```
# Tekil bir dosyanın SHA256 özetini üretme
sha256sum shady_attachment.pdf

# Örnek çıktı:
# 025ba9ce4a2118a9ca7b115c8869ff73bc16bad3732ba359cef1e60ad8f961f9  shady_attachment.pdf
```

- `sha256sum`: Linux coreutils paketiyle gelen SHA-256 kriptografik özetleme aracı.
    
      
    
- `shady_attachment.pdf`: Analiz edilecek hedef dosya parametresi.
    
      
    

### Defanging (Zararsızlaştırma) Kuralları

Raporlara ve biletlere eklenen zararlı adreslerin tıklanmasını önlemek için standart biçimler:

  

```
Orijinal URL:   https://t.co/yuxfZm8KPg?amp=1
Defanged URL:   hxxps[://]t[.]co/yuxfZm8KPg?amp=1

Orijinal IP:    209.85.167.226
Defanged IP:    209[.]85[.]167[.]226
```

## 🔬 4. Pratik Laboratuvar İncelemeleri (Case Studies)

### 📌 Case 1: Netflix Temalı Oltalama (`Phish3Case1.eml`)

- **Taklit Edilen Marka:** Netflix.
    
      
    
- **Hedef Alıcı:** `redacted@yahoo.com`.
    
      
    
- **Sahte Gönderici (From):** `JGQ47wazXe1xYVBrkeDg-JOg7ODDQwWdR@JOg7ODDQwWdR-yVkCaBkTNp.gogolecloud.com`.
    
      
    
- **Received IP:** `10.197.37.234` / **Originating Mail Server IP (Defanged):** `209[.]85[.]167[.]226`.
    
      
    
- **İnceleme Altındaki Domain (Return-Path / X-Relaying-Domain):** `etekno[.]xyz`.
    
      
    
- **Shortened URL (Defanged):** `hxxps[://]t[.]co/yuxfZm8KPg?amp=1`.
    
      
    

### 📌 Case 2: ANY.RUN PDF Analizi (`Payment-updateid.pdf`)

- **Sandbox Sınıflandırması:** `Suspicious activity` (Şüpheli Aktivite).
    
      
    
- **Ek Dosya Adı:** `Payment-updateid.pdf`.
    
      
    
- **SHA256 Hash Değeri:** `cc6f1a04b10bcb168aeec8d870b97bd7c20fc161e8310b5bce1af8ed420e2c24`.
    
      
    
- **Zararlı Bağlantı Kurulan IP'ler (Defanged):** `2[.]16[.]107[.]24`, `2[.]16[.]107[.]83`.
    
      
    
- **Kötü Trafik Üreten Windows Süreci:** `svchost.exe` (`AcroRd32.exe` üzerinden tetiklenen ağ anomalisi).
    
      
    

### 📌 Case 3: ANY.RUN Excel Analizi (`CBJ200620039539.xlsx`)

- **Sandbox Sınıflandırması:** `Malicious Activity` (Zararlı Aktivite).
    
      
    
- **Ek Dosya Adı:** `CBJ200620039539.xlsx`.
    
      
    
- **SHA256 Hash Değeri:** `5f94a66e0ce78d17afc2dd27fc17b44b3ffc13ac5f42d3ad6a5dcfb36715f3eb`.
    
      
    
- **Zararlı Domainler (Alfabetik & Defanged):** `biz9holdings[.]com`, `findresults[.]site`, `ww38[.]findresults[.]site`.
    
      
    
- **Zararlı IP Adresleri (Küçükten Büyüğe & Defanged):** `75[.]2[.]11[.]242`, `103[.]224[.]182[.]251`, `204[.]11[.]56[.]48`.
    
      
    
- **İstismar Edilen Güvenlik Açığı:** **`CVE-2017-11882`** (Microsoft Office Equation Editor Bellek Bozulması / RCE Açığı).
    
      
    

> [!WARNING]
> 
> **Kritik SOC Uyarısı (CVE-2017-11882):**
> 
> Bu zafiyet, saldırganların herhangi bir kullanıcı etkileşimi veya makro izni gerekmeksizin sadece doküman açıldığında `EQNEDT32.EXE` üzerinden uzaktan kod çalıştırmasını (RCE) sağlar. Eski ancak oltalama kampanyalarında en sık kullanılan ofis zafiyetlerinden biridir.
> 
>
