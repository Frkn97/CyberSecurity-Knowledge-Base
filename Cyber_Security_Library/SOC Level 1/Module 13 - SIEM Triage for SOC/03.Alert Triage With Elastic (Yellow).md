# 🔍 Alert Triage With Elastic

**Etiketler:** `#SOC` `#SIEM` `#Elasticsearch` `#Kibana` `#KQL` `#AlertTriage` `#ProxyLogon` `#WebShell` `#Sysmon` `#WindowsLogs` `#TryHackMe`

## 1. Mimari Yapı ve Saldırı Rekonstrüksiyon Hattı

Bu operasyonel senaryoda, bir Yönetilen Güvenlik Hizmeti Sağlayıcısında (MSSP) görev yapan Seviye 1 (L1) analist olarak kurban şirket (_SomeCorp_) altyapısında tetiklenen çok aşamalı güvenlik alarmları incelenmektedir. İnceleme platformu olarak Elastic Stack (Elasticsearch & Kibana) ve sorgulama dili olarak **KQL (Kibana Query Language)** kullanılmaktadır.

  

Saldırgan dış web katmanından girip uç noktada veri arşivlemeye kadar uzanan klasik bir ihlal zinciri (**Kill Chain**) icra etmiştir:

## 2. Triaj Metodolojisi ve Çapraz Log Korelasyonu

### A. Web Log İncelemesi (`_index:weblogs`)

- **ProxyLogon Denemesi:** Saldırganın `python-requests/2.25.1` gibi bir script kütüphanesi kullanarak `proxyLogon.ecp` uç noktasına doğrudan `POST` istekleri atması, otomatize bir istismar (exploit) girişiminin göstergesidir.
    
      
    
- **Web Shell Göstergesi (`cmd=`):** İstismar sonrası bırakılan veya çağrılan dosyalarda (`errorEE.aspx`), HTTP istek parametresinde doğrudan işletim sistemi komutlarının geçmesi (`?cmd=hostname`, `?cmd=whoami`) web kabuğu etkileşiminin kesin kanıtıdır.
    
      
    

> [!WARNING]
> 
> **Web Alarmlarında Yalnızca Web Loguna Takılı Kalma Tuzağı:**
> 
>   
> 
> Web sunucusunda komut yürütüldüğü görüldüğü an analiz web loglarında bırakılamaz. Saldırganın sunucu üzerinde yerel oturum açıp açmadığını veya interaktif bir RDP/SSH bağlantısına zıplayıp zıplamadığını anlamak için derhal **Ana Makine Güvenlik Loglarına (Windows Event ID 4624 / Linux auth.log)** pivot yapılmalıdır!
> 
>   

### B. Uç Nokta ve Kimlik Analitiği (`winlog.event_id`)

- **Mesai Dışı Yönetici Girişi (EID 4624):** Saat 05:11'de `Administrator` hesabının daha önce web saldırısını yapan dış IP (`203.0.113.55`) üzerinden oturum açması, kimlik bilgilerinin çalındığını ya da web shell üzerinden parola sıfırlandığını gösterir.
    
      
    
- **Kullanıcı Yönetimi (EID 4720 & 4732):**
    
      
    - **EID 4720:** Yeni bir yerel kullanıcı hesabı oluşturulduğunda tetiklenir (`svc_backup`).
        
          
        
    - **EID 4732:** Güvenlik grubuna üye eklendiğinde tetiklenir (`Administrators`, `Remote Desktop Users`).
        
          
        

### C. Alarmsız Saldırı Adımlarını Yakalama: Meşru Araç İstismarı (LOLBin)

Kurumsal SIEM sistemleri her yürütmeyi alarm olarak üretmez; aksi takdirde alarm yorgunluğu (alert fatigue) oluşur.

  

- Müşteri şirket düzenli olarak `Rar.exe` kullandığı için SIEM bu dosyaya kural yazmamış olabilir.
    
      
    
- **Analist Refleksi:** Şüpheli bir oturum veya arka kapı kullanıcısı (`svc_backup`) tespit edildiğinde, o kullanıcının veya oturumun başlattığı tüm süreçler (`process.name: "Rar.exe"`) taranmalıdır.
    
      
    
- Saldırganın `cmd.exe` altından `finance_it_archive.rar` adıyla finans/BT verilerini paketlediği ortaya çıkarılmıştır (Collection aşaması).

## 4. Tüm Kibana KQL Sorguları ve Parametre Referansı

### A. Web Sunucusu (IIS) Log Sorguları

HTTP

```
-- 1. Yalnızca IIS web sunucu loglarını filtreleme
_index:weblogs

-- 2. Saldırgan IP'sine ait POST isteklerini ve ProxyLogon etkileşimini dökme
_index:weblogs and client.ip:203.0.113.55 and http.request.method:POST

-- 3. errorEE.aspx web kabuğuna giden GET isteklerini inceleme
_index:weblogs and client.ip:203.0.113.55 and http.request.method:GET and errorEE.aspx

-- 4. Web kabuğu üzerinden çalıştırılan tüm komut parametrelerini (cmd=) sayma
_index:weblogs and client.ip:"203.0.113.55" and http.request.method:"GET" and url.path:*cmd=*
```

### B. Windows Güvenlik ve Sysmon Korelasyon Sorguları

HTTP

```
-- 1. Saldırgan IP'sinden gelen mesai dışı Administrator oturumunu (EID 4624) yakalama
@timestamp >= "2025-07-20T05:11:22" and winlog.event_id:4624 and host.name:winserv2019.some.corp and winlog.event_data.TargetUserName:Administrator

-- 2. Sysmon EID 1: Oturum anında başlayan ilk süreçleri ve PID değerini bulma
@timestamp >= "2025-07-20T05:11:22" and winlog.event_id:1 and user.name:Administrator

-- 3. Kullanıcı Yönetimi Olaylarını (Kullanıcı oluşturma/değiştirme) listeleme
@timestamp >= "2025-07-20T05:13:10.000" and winlog.channel:Security and winlog.task:"User Account Management"

-- 4. Administrator tarafından cmd.exe üzerinden yürütülen komutları izleme
@timestamp >= "2025-07-20T05:13:15" and process.parent.name:cmd.exe and user.name:Administrator

-- 5. Sysmon süreçleri ile Grup Yönetimi Güvenlik olaylarını (EID 4732) birleştirme
@timestamp >= "2025-07-20T05:13:15" and (winlog.event_id:4732 or process.parent.name:cmd.exe)
```

### C. PowerShell ve Meşru Araç (LOLBin) İnceleme Sorguları

HTTP

```
-- 1. PowerShell Script Block Logging (EID 4104) ile düz metin komutları çekme
@timestamp >= "2025-07-20T05:13:15" and event.module:powershell and event.code:4104

-- 2. Alarmsız çalışan Rar.exe sıkıştırma aracını ve oluşturulan arşivi tespit etme
process.name:"Rar.exe"
```

## 6. Tekrar Kategorisi ve Pazar Stratejisi

- **Kategori Sınıfı:** 🟡 **Sarı (Kavramsal Triaj & KQL Çok Katmanlı Korelasyon / 3 Dakika)**
    
      
    
- **Gerekçe:** Web Shell tespiti (`cmd=` parametresi), ProxyLogon saldırı izi, EID 4624 $\rightarrow$ Sysmon EID 1 $\rightarrow$ EID 4720/4732 zinciri ve PowerShell 4104 Script Block Logging kullanımı hem Splunk hem Elastic tabanlı kurumsal SOC mülakatlarının doğrudan vaka sorusudur.
    
      
    
- **Pazar Günü 3 Dakikalık Tekrar Stratejisi:**
    
      
    1. **1. Dakika:** KQL ve Web Shell kalıbını hatırla: Web loglarında `url.path:*cmd=*` ve `status:200` gördüğünde analist doğrudan Web Shell (True Positive) hükmü verir.
        
          
        
    2. **2. Dakika:** Windows Kullanıcı ve Grup Olay Kodlarını eşleştir:
        
          
        - **4720:** Yeni kullanıcı hesabı oluşturuldu (`svc_backup`).
            
              
            
        - **4732:** Kullanıcı güvenlik grubuna eklendi (`Administrators`, `Remote Desktop Users`).
            
              
            
        - **4104:** PowerShell komutunun açık metin betik bloğu (`net group "Domain Admins" /domain`).
            
              
            
    3. **3. Dakika:** Mülakat tuzağına yanıt ver: _"SIEM'de alarm üretmeyen bir işlem (Rar.exe) zararlı olabilir mi?"_ $\rightarrow$ _"Evet, saldırganlar meşru yazılımları (LOLBin) tespit sistemlerini atlatmak için kullanır; bu nedenle şüpheli oturum bağlamındaki tüm süreçler korele edilmelidir."_
