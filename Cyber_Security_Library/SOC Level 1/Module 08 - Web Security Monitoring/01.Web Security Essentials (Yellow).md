## 🏛️ 1. Mimari Yapı ve Web Ekosistemi (Web Architecture & Request-Response Cycle)

Geleneksel masaüstü yazılımlardan modern bulut/SaaS tabanlı web uygulamalarına geçiş; hız, erişilebilirlik ve bakım kolaylığı sağlarken saldırı yüzeyini (**Attack Surface**) küresel ölçeğe taşımıştır. Web uygulamaları 7/24 internete açıktır ve arkalarında kritik veritabanları ile kurumsal iç ağları barındırırlar.

  

Bir web servisinin çalışması ve korunması **3 temel mimari katmandan** oluşur:

  

```
                      [ 🌐 INTERNET / İSTEMCİ TARAYICISI ]
                                       │
                      [ 🛡️ CDN & WAF (Ters Proxy / Sınır) ]
                                       │
                                       ▼
 ┌───────────────────────────────────────────────────────────────────────────┐
 │ 🖥️ HOST MACHINE (Altyapı & İşletim Sistemi: Linux / Windows)              │
 │                                                                           │
 │   ┌───────────────────────────────────────────────────────────────────┐   │
 │   │ ⚙️ WEB SERVER (Hizmet & Protokol Motoru: Nginx / Apache / IIS)     │   │
 │   │                                                                   │   │
 │   │   ┌───────────────────────────────────────────────────────────┐   │   │
 │   │   │ 📦 APPLICATION (Kod, Veri, İş Mantığı, Arayüz & DB Erişimi)│   │   │
 │   │   └───────────────────────────────────────────────────────────┘   │   │
 │   └───────────────────────────────────────────────────────────────────┘   │
 └───────────────────────────────────────────────────────────────────────────┘
```

### 🔹 Web Servisinin 3 Temel Bileşeni

1. **Application (Uygulama Katmanı):** Sitenin nasıl göründüğünü, iş mantığını ve veritabanı etkileşimini yöneten kodlar (PHP, Python, JS, HTML/CSS), şablonlar ve fonksiyonlar bütünü.
    
      
    
2. **Web Server (Web Sunucusu Katmanı):** Uygulamayı barındıran, HTTP/HTTPS isteklerini dinleyen ve istemciye uygun yanıtı (`Response`) üreten yazılım motoru.
    
      
    
3. **Host Machine (Barındırıcı Sistem / OS Katmanı):** Web sunucusunu ve uygulama ortamını üzerinde çalıştıran fiziksel sunucu, sanal makine veya konteyner işletim sistemi (Linux/Windows).
    
      
    

## 👥 2. Web Güvenliğinde Sorumluluk Modeli ve Tarihsel İhlaller

```
[ Web Uygulama Sahibi (Owner) ]                [ Web Uygulama Kullanıcısı (User) ]
 • 7/24 kesintisiz güvenlik sağlama              • Verilerinin güvensiz saklanma riski
 • Dünyanın her yerinden gelen saldırılar        • Tarayıcı ihlalinde hesapların çalınması
 • Kullanıcı verilerini koruma nihai yasal mesuliyeti • Kimlik hırsızlığı ve finansal kayıp riski
```

> [!WARNING]
> 
> **Nihai Sorumluluk İlkesi:** Bir web uygulamasındaki verilerin güvenliğinden son tahlilde **Web Uygulama Sahibi (Web App Owner)** sorumludur. Kullanıcı yalnızca sisteme güvenir; altyapının sıkılaştırılması kurumun yükümlülüğündedir.
> 
>   

### 📜 Gerçek Dünya İhlal Örnekleri (Real-World Breaches)

- **[Equifax İhlali (2017)](https://www.equifax.com):** Apache Struts üzerindeki bir uzaktan kod çalıştırma zafiyeti ([Apache Vulnerability](https://nvd.nist.gov/vuln/detail/cve-2017-5638)) istismar edilerek yaklaşık 150 milyon Amerikan vatandaşının hassas kimlik ve finansal verisi çalındı.
    
      
    
- **[Capital One İhlali (2019)](https://www.capitalone.com):** Hatalı yapılandırılmış bir Web Application Firewall (WAF) kural seti üzerinden SSRF (Server-Side Request Forgery) zinciri işletilerek şirketin AWS bulut altyapısına ve 100 milyondan fazla müşterinin veritabanına yetkisiz erişim sağlandı.

## 🛡️ 4. Katmanlı Savunma ve En İyi Güvenlik Uygulamaları (Defense-in-Depth)

Web güvenliği tek bir araçla sağlanamaz. Tehditleri durdurmak veya zararlarını sınırlandırmak için uygulanan güvenlik kontrollerine **Mitigation (Hafifletme/Azaltma)** denir.

  

```
       [ UYGULAMA KATMANI ] ──► Güvenli Kodlama, Girdi Doğrulama (Sanitization), Rol Bazlı Erişim (RBAC)
               │
       [ SUNUCU KATMANI ]   ──► Erişim Logları (Access Logs), WAF Entegrasyonu, CDN Koruması
               │
       [ İŞLETİM SİSTEMİ ]  ──► En Az Yetki (Least Privilege), Sistem Sıkılaştırma, Antivirüs/EDR
               │
     [ ORTAK ZORUNLULUK ]  ──► Güçlü Kimlik Doğrulama (MFA) & Yama Yönetimi (Patch Management)
```

### 🔹 Katman Bazlı Koruma Matrisi

|**Güvenlik Katmanı**|**Alınması Gereken Önlemler**|**Güvenlik Amacı ve Tehdit Engelleme**|
|---|---|---|
|**1. Application (Uygulama)**|• Güvenli Kodlama (Secure Coding)<br><br>  <br>  <br><br>• Girdi Doğrulama & Temizleme (Input Validation & Sanitization)<br><br>  <br>  <br><br>• Rol Bazlı Erişim Kontrolü (Access Control)|SQL Injection, XSS, RCE gibi kod seviyesi enjeksiyon açıklarını engeller; kullanıcıların yetkisiz verilere erişmesini kısıtlar.|
|**2. Web Server (Sunucu)**|• Detaylı Erişim Kayıtları (Access Logging)<br><br>  <br>  <br><br>• Web Application Firewall (WAF)<br><br>  <br>  <br><br>• Content Delivery Network (CDN)|Gelen HTTP trafiğini sınırlar, bilinen saldırı payload'larını filtreler, kaynak sunucunun IP adresini gizler.|
|**3. Host Machine (İşletim Sistemi)**|• En Az Yetki İlkesi (Least Privilege)<br><br>  <br>  <br><br>• Sistem Sıkılaştırma (Unused port/service disable)<br><br>  <br>  <br><br>• Antivirüs / EDR Kurulumu|Servislerin `root`/`Administrator` olarak çalışmasını engeller, olası bir web kabuğu (web shell) yüklemesini engeller.|
|**Ortak / Tüm Katmanlar**|• Güçlü Kimlik Doğrulama (Strong Auth / MFA)<br><br>  <br>  <br><br>• **Yama Yönetimi (Patch Management)**|Bilinen yazılım açıklarının (N-day) istismar edilmesini ve parola kaba kuvvet saldırılarını önler.|

## 📜 5. Web Sunucu Erişim Logları Analizi (Access Logs)

Web sunucuları aldıkları her HTTP isteği için bir kayıt oluşturur. Bu loglar bir saldırı zincirinin adli incelemesinde temel dayanaktır.

  

Plaintext

```
10.10.10.100 - - [07/Sep/2026:14:22:10 +0000] "GET /index.html HTTP/1.1" 200 4521 "-" "Mozilla/5.0..."
10.10.10.100 - - [07/Sep/2026:14:22:15 +0000] "GET /login.html HTTP/1.1" 200 2310 "-" "Mozilla/5.0..."
10.10.10.100 - - [07/Sep/2026:14:22:25 +0000] "POST /login.html HTTP/1.1" 302 - "-" "Mozilla/5.0..."
10.10.10.100 - - [07/Sep/2026:14:22:30 +0000] "GET /myaccount.html HTTP/1.1" 200 8940 "-" "Mozilla/5.0..."
```

> [!INFO]
> 
> **HTTP Metot Ayrımı:**
> 
>   
> 
> - `GET`: Sunucudan bir kaynağı (web sayfası, görsel, script) çekmek için kullanılır.
>     
>       
>     
> - `POST`: Sunucuya veri göndermek/yüklemek için kullanılır (Örn: Form doldurma, parola iletme).
>     
>       
>     

## 🌐 6. CDN ve WAF Mimarisi (Perimeter Protections)

### 🔹 Content Delivery Network (CDN)

CDN'ler içerikleri son kullanıcıya en yakın coğrafi sunucularda (Edge Servers) önbelleğe alarak hızı artırır. Güvenlik tarafında ise kaynak sunucu ile internet arasında tampon bölge (**Buffer**) oluşturur.

  

- **IP Masking:** Gerçek menşe sunucu (Origin Server) IP'sini gizler. Saldırganın doğrudan sunucuya saldırmasını engeller.
    
      
    
- **DDoS Koruması:** Devasa trafik dalgalarını edge ağı üzerinde emerek ana sunucunun çökmesini önler.
    
      
    
- **Zorunlu HTTPS:** Uçtan uca şifreli TLS iletişimini varsayılan hale getirir.
    
      
    
- **Entegre WAF:** [Cloudflare](https://www.cloudflare.com/), [Amazon CloudFront](https://aws.amazon.com/cloudfront/), [Azure Front Door](https://azure.microsoft.com/en-us/products/frontdoor) gibi modern CDN'ler yerleşik WAF katmanıyla gelir.
    
      
    

### 🔹 Web Application Firewall (WAF) Türleri ve Tespit Metotları

WAF, 7. Katman (Uygulama Katmanı) HTTP/HTTPS trafiğini inceleyen özelleşmiş güvenlik duvarıdır.

  

```
[ WAF DAĞITIM MODELLERİ ]
 ├── 1. Cloud-Based (Ters Proxy) ──► Sunucunun önünde bulutta durur, kolay ölçeklenir (Örn: Cloudflare).
 ├── 2. Host-Based (Sunucu Üstü)  ──► Doğrudan web sunucusunun içine kurulur, uygulama bazlı ince ayar sağlar.
 └── 3. Network-Based (Fiziksel)   ──► Ağ sınırına donanım/sanal cihaz olarak konur, kurumsal omurgalara uygundur.
```

|**WAF Özelliği / Tekniği**|**Tespit Yöntemi (Detection Method)**|**Pratik Örnek / İnceleme İmzası**|
|---|---|---|
|**Signature-Based Detection**|Bilinen saldırı kalıpları veya zararlı araç imzalarıyla eşleştirme yapar.|User-Agent başlığında bilinen bir istismar aracının geçmesi: `User-Agent: sqlmap/1.8.1`|
|**Heuristic-Based Detection**|İsteklerin bağlamını, yapısını ve sıra dışı karakter dizilimlerini analiz eder.|Arama parametresinde XSS kalıbı içeren özel karakter dizilimi: `search?q=%3Cscript%20(1)`|
|**Anomaly & Behavioral Analysis**|Normal trafik davranışından (Baseline) gerçekleşen istatistiksel sapmaları yakalar.|Tek bir IP'den kısa sürede anormal sayıda ardışık POST login denemesi gelmesi.|
|**Location & IP Reputation Filtering**|Tehdit istihbaratı (Threat Intel) ve Coğrafi IP (Geo-IP) veritabanlarını kullanır.|Hizmet alanı dışındaki şüpheli ülkelerden veya bilinen Tor çıkış noktalarından gelen istekleri engelleme.|

### 🔹 Antivirüs (AV) Katmanı

Antivirüs sistemleri web katmanını doğrudan filtrelemez; ancak host makine seviyesinde **Defense-in-Depth** prensibinin kritik bir parçasıdır. Web açıkları üzerinden yüklenen **Web Shell** (arka kapı betikleri), post-exploitation araçları ve zararlı çalıştırılabilir dosyaları tespit edip karantinaya alır.

## 🚦 8. Tekrar Kategorisi & 3 Dakikalık Pazar Tekrar Stratejisi

### 🟡 Sarı Sınıf: Kavramsal / 3 Dk Soru-Cevap & Mimari Savunma

Bu modül **Sarı Sınıf** (Kavramsal / Hızlı Soru-Cevap & Katmanlı Mimari) kategorisindedir. Karmaşık terminal bayt hesaplamaları yerine webin 3 sacayağını (App, Server, Host) ve koruma mekanizmalarını zihinde diri tutmayı amaçlar.

  

### ⏱️ Pazar Günü 3 Dakikalık Hızlı Tekrar Rutini

1. **3 Katmanlı Savunma Şemasını Hatırla (1. Dakika):**
    
      
    - _Application:_ Girdi doğrulama (Sanitization), Güvenli kodlama.
        
          
        
    - _Web Server:_ Access Logs, WAF (İstek filtreleme), CDN (Origin IP gizleme & DDoS).
        
          
        
    - _Host Machine:_ Least Privilege (En az yetki), Sıkılaştırma, Antivirüs (Web shell yakalama).
        
          
        
2. **WAF Tespit Yöntemlerini Eşleştir (2. Dakika):**
    
      
    - `Signature-Based`: Bilinen User-Agent (`sqlmap`) veya exploit kalıpları.
        
          
        
    - `Heuristic`: URL içindeki zararlı karakter dizilimleri (`<script>`).
        
          
        
    - `Behavioral / Anomaly`: Kısa sürede aşırı sayıda POST isteği.
        
          
        
    - `Geo-IP / Reputation`: Tehdit istihbaratı ve ülke filtreleri.
        
          
        
3. **Mülakat Cümlesi (3. Dakika):**
    
    _"Bir web uygulamasını savunurken sadece kod seviyesinde girdi temizlemek yetmez; CDN ile gerçek sunucu IP'si gizlenmeli, WAF ile 7. katman istekleri filtrelenmeli ve sunucunun çalıştığı host makine en az yetki ilkesiyle sıkılaştırılmalıdır."_
