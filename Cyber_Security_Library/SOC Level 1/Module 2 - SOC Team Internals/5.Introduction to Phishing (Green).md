## 🏗️ Mimari Yapı

**SOC Simulator**, canlı bir SOC (Güvenlik Operasyon Merkezi) ortamını simüle ederek junior analistlerin gerçek zamanlı alarmları triyaj etme, IoC (Indicator of Compromise) analizi yapma, karara varma (Verdict) ve vaka raporu (Case Report) yazma kaslarını geliştiren interaktif bir platformdur.

Bu senaryoda, **Elastic Stack (ELK)** tabanlı bir SIEM ortamı üzerinde **Oltalama (Phishing)** temalı alarmların incelemesi gerçekleştirilmektedir.

```
                     [ SOC Simulator Oltalama Triyaj Mimarisi ]

        ▼                                ▼                                ▼
[ 1. Inbound Email Log ]       [ 2. Firewall / Proxy Logs ]     [ 3. TryDetectThis Lookup ]
- Gönderici (Sender)            - Erişim Durumu (Allowed/Blocked) - Domain / URL Reputasyonu

        │                                │                                │
        └────────────────────────────────┴────────────────────────────────┘
                                         │
                                         ▼
                            [ 4. AI-Evaluated Case Report ]
                            - Incident Classification (TP/FP)
                            - Who, What, Where, Why (5 Ws)
                            - Escalation & Remediation Actions
```

### Temel Mimariler ve İnceleme Katmanları

- **SIEM Alert Queue (Alarm Kuyruğu):** Gelen oltalama e-postalarını ve şüpheli dış bağlantıları önceliklerine göre sıralar.
    
- **TryDetectThis (Tehdit İstihbaratı / Lookup):** Etki alanlarının (domain), URL'lerin ve IP adreslerinin itibarını (reputation) sorgulayan dahili tehdit istihbaratı aracıdır.
    
- **Firewall / Proxy Logs:** Kullanıcının e-postadaki zararlı bağlantıya tıklayıp tıklamadığını, bağlantının güvenlik duvarı tarafından engellenip engellenmediğini gösteren trafik katmanıdır.
    
- **AI Report Analyzer:** Analistin yazdığı vaka raporunu **"Who, What, Where, Why" (5 Ws)** prensiplerine, IP adreslerinin eksiksizliğine ve önerilen aksiyonlara göre puanlayan değerlendirme sistemidir.
    

## 💻 Tüm Komutlar, Parametreler ve Çalışma Mekanizmaları

Bu odada komut satırı bulunmamakta; SIEM arayüzü, **TryDetectThis** sorgulama paneli ve **Case Report (Vaka Raporlama)** metin alanları yer almaktadır.

### A. Triyaj ve Sorgulama Mantığı (TryDetectThis Lookup)

SOC Simulator içerisinde itibar analizi yapılırken şu adımlar izlenir:

1. Alarm detayındaki domain/URL veya IP adresi kopyalanır.
    
2. Dahili arama aracı olan **TryDetectThis** alanına yapıştırılır.
    
3. Çıkan sonuç:
    
    - **Clean / Safe:** Alan adı güvenilirdir. (Örn: `hrconnex.thm`)
        
    - **Malicious / Phishing:** Alan adı veya URL zararlıdır. (Örn: `bit.ly/3sHkX3da12340`, `m1crosoftsupport.co`)

## 🧠 Uzman Notları ve AI Rapor Geri Bildirimi Analizi

> ⚠️ **MÜLAKAT HAPI - KUSURSUZ VAKA RAPORU İÇİN "5 Ws" VE IP ADRESLERİ:**
> 
> AI Raporlama Sisteminin geri bildirimlerinde görüldüğü üzere, sadece _"Saldırı var, engellendi"_ demek rapordan puan kaybettirir! Bir SOC analisti raporunda şu detayları **eksiksiz** sunmalıdır:
> 
> 1. **Who (Kim):** Etkilenen kullanıcının e-postası VE **Dahili IP adresi** (`10.20.2.17`).
>     
> 2. **What (Ne):** Saldırının türü, zararlı URL veya ek dosya adı.
>     
> 3. **Where (Nereye):** Saldırganın IP adresi (`67.199.248.11`) veya zararlı domain (`m1crosoftsupport.co`).
>     
> 4. **Why (Neden):** Neden bu kararı verdin? (`TryDetectThis reported URL as malicious`, `Firewall blocked outbound traffic`).
>     
> 5. **Remediation (Çözüm Önerisi):** Domain'in karantinaya alınması, kullanıcı eğitimi veya IP bloklanması.
>     

> 💡 **SEKTÖREL İPUCU - FIREWALL ENGELLEDİĞİ HALDE NEDEN ESKALE EDİLİR? (ID: 8816):**
> 
> Bir kullanıcı zararlı bağlantıya tıkladığında Firewall bağlantıyı engellemiş olsa bile (True Positive), eğer olay devam eden bir oltalama dalgasının parçasıysa L2 veya Tehdit Avcılığı (Threat Hunting) ekiplerine **eskale edilebilir**. Amaç, benzer diğer domainlerin veya IP bloklarının organizasyon genelinde engellenip engellenmediğini doğrulamaktır.

> 🚨 **KRİTİK UYARI - TYPOSQUATTING (ALAN ADI TAKLİDİ) TEHLİKESİ:**
> 
> ID 8817 vakasında kullanılan `m1crosoftsupport.co` adresi **Typosquatting** (harf/rakam değiştirerek taklit etme) örneğidir. "o" harfi yerine "1" yazılmıştır. Analistler alan adlarını incelerken tırnak işaretlerine ve harf oyunlarına son derece dikkat etmelidir!

## 🗃️ Soru-Cevap ve Vaka Analiz Anahtarı

### Case ID 8814 (HR Onboarding Email)

- **Durum:** `False Positive (FP)`
    
- **Neden:** `hrconnex.thm` domaini şirketin yeni 3. parti İK ortağıdır. TryDetectThis sorgusunda temiz çıkmıştır.
    
- **Vaka Raporu Şablonu:**
    
    > `False Positive. The domain hrconnex.thm was verified using TryDetectThis and confirmed to be safe. The email is a legitimate onboarding communication for employee J. Garcia (10.20.2.8).`
    

### Case ID 8815 (Amazon Phishing)

- **Durum:** `True Positive (TP)`
    
- **Neden:** `urgents@amazon.biz` adresinden gelen e-postadaki `bit.ly/3sHkX3da12340` kısaltılmış URL'i TryDetectThis tarafından zararlı olarak işaretlenmiştir.
    
- **Eskalasyon:** Gereksiz (Firewall çıkış bağlantısını engellemiştir).
    
- **Vaka Raporu Şablonu:**
    
    > `True Positive. User H. Harris (10.20.2.17) received a phishing email from urgents@amazon.biz containing a malicious URL (bit.ly/3sHkX3da12340). TryDetectThis confirmed the URL is malicious. Firewall successfully blocked the connection.`
    

### Case ID 8816 (Blocked Blacklisted URL)

- **Durum:** `True Positive (TP)`
    
- **Dahili IP:** `10.20.2.17` | **Dış IP:** `67.199.248.11`
    
- **Neden:** Kullanıcı zararlı bağlantıya erişmeye çalışmış, Firewall engellemiştir.
    
- **Eskalasyon:** Evet (Tehdit istihbaratı incelemesi için L2'ye sevk edilebilir).
    

### Case ID 8817 (Microsoft Phishing - Typosquatting)

- **Durum:** `True Positive (TP)`
    
- **Zararlı Domain:** `m1crosoftsupport.co` | **Kullanıcı:** `c.allen@thetrydaily.thm` (`10.20.2.25`)
    
- **Neden:** Sahte Microsoft e-postasıyla panik oluşturulmuş, kullanıcı linke tıklamıştır. Firewall bağlantıyı kaçırmıştır (engellememiştir).
    
- **Eskalasyon:** **Kesinlikle Evet (Critical Escalation).**
    
- **Aksiyon:** Domain derhal kara listeye alınmalı ve etkilenen makinede güvenlik taraması başlatılmalıdır.
    

### Case ID 8818 (Onboarding Finalize Profile)

- **Durum:** `False Positive (FP)`
    
- **Neden:** ID 8814'te sorunu bildirilen meşru onboarding e-postasının sisteme ulaşan asıl halidir. Domain güvenlidir.
