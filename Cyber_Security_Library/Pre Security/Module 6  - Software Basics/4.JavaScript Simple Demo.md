## 🏗️ 2. Değişken Tanımlama Kuralları: `let` vs. `const` (Mülakat Bilgisi)

Python'ın aksine JavaScript'te bir veri tanımlanırken onun kararlılık durumunu belirten anahtar kelimeler (`let` veya `const`) kullanılmalıdır:

- **`let` Anahtar Kelimesi (Mutable / Değişken):** Değeri programın ilerleyen akışında güncellenebilen, değiştirilebilen dinamik hafıza alanları için kullanılır. (Örn: Oyundaki deneme sayısı `let tries = 0;` veya kullanıcının tahmini `let guess = 0;`).
    
- **`const` Anahtar Kelimesi (Immutable / Sabit):** Tanımlandıktan sonra değeri program boyunca **asla değiştirilemeyen** sabit alanlar için kullanılır. (Örn: Bilgisayarın seçtiği gizli hedef sayı `const secret`).
    

### 🎲 JavaScript ile Rastgele Tam Sayı Üretim Anatomisi

Bilgisayarın 1 ile 20 arasında gizli bir tam sayı seçmesini sağlayan formülün teknik kırılımı:

JavaScript

```
const secret = Math.floor(Math.random() * 20) + 1;
```

- `Math.random()`: `0` (dahil) ile `1` (hariç) arasında rastgele bir ondalıklı sayı üretir (Örn: `0.372`).
    
- `* 20`: Üretilen aralığı genişleterek `0` ile `19.99` arasına esnetir (Örn: `7.44`).
    
- `Math.floor()`: Sayının virgülden sonraki ondalık kısmını atarak **aşağıya yuvarlar** (Örn: `7.44` ➡️ `7`).
    
- `+ 1`: `0-19` arası olan tam sayı aralığını, hedefimiz olan `1-20` aralığına öteler/kaydırır.
    

## 📥 3. Node.js ve Asenkron Giriş / Çıkış (Readline Labirenti)

Python'da tek satırlık `input()` ile yapılan işlem, Node.js ortamında sunucu odaklı mimari nedeniyle daha kontrollü bir kütüphane kurulumu gerektirir. Node.js, gelen web isteklerini işlerken kullanıcı girdi yazana kadar tüm sunucuyu dondurmamak (**freeze**) üzere tasarlanmıştır. Bu varsayılan davranışı aşmak için asenkron yapılar kullanılır:

### 🎙️ Mikrofon ve Try-Finally Mekanizması

Terminalden veri alabilmek için standart girdi/çıktı modülleri (`stdin / stdout`) çağrılarak bir iletişim kanalı arayüzü (**`rl`**) oluşturulur.

- **`await rl.question()`:** Kullanıcı klavyeden cevabı yazıp onaylayana kadar sistemi kibarca duraklatır (pause neatly). Gelen veri her zaman döküman (string) tipindedir.
    
- **`parseInt(text, 10)`:** Kullanıcıdan alınan metin tabanlı girdiyi 10'luk tabanda (base 10) bir tam sayıya (Integer) dönüştürür.
    
- **`finally { rl.close(); }`:** Sistem kaynaklarının tükenmesini engellemek için, kod bloğu tamamlansa da hata alıp çökse de en sonda `finally` bloğu tetiklenir ve açık kalan iletişim kanalı (`rl.close()`) güvenle kapatılır. Siber güvenlikte kaynak sızıntılarını (resource leaks) engellemek adına kritik bir alışkanlıktır.

## 🛡️ 6. Siber Güvenlik Analisti Perspektifi: Neden Öğreniyoruz?

1. **XSS (Cross-Site Scripting / Siteler Arası Betik Çalıştırma):** Web siber güvenliğinin en yaygın zafiyet türüdür. Saldırganlar web sitelerindeki filtrelenmemiş girdi alanlarına zararlı JavaScript kodları enjekte ederek, siteyi ziyaret eden kurbanların oturum çerezlerini (**Session Cookies / Tokens**) çalarlar, tarayıcıları manipüle ederler veya sahte formlarla kimlik avı yaparlar. JS bilmek, bu atakları kod seviyesinde analiz etmek ve engellemek için hayati şarttır.
    
2. **Zararlı Web Script Analizi (Deobfuscation):** Saldırganlar web sitelerine sızdırdıkları JavaScript backdoor kodlarını veya reklam virüslerini (malware) analiz edilmesin diye karmaşıklaştırırlar (obfuscation). Bir analist, tarayıcı konsolunu (`F12 Console`) ve `console.log()` çıktılarını kullanarak bu kodları adım adım çözmek ve arka planda hangi C2 sunucusuyla konuştuğunu deşifre etmek zorundadır.
