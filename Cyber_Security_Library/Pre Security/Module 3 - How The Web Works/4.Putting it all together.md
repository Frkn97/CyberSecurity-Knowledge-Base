# 📓THM - Putting It All Together (Web Altyapı Mimarisi, Sunucu Sistemleri ve Güvenlik Bileşenleri)

**Tags:** #WebSecurity #Infrastructure #WAF #LoadBalancer #CDN #VirtualHosts #Backend #BlueTeamFundamentals

## 🌐 1. Büyük Resim: Bir Web İsteğinin Yolculuğu

Bir web tarayıcısından sayfa isteği atıldığında arka planda şu temel çarklar sırasıyla döner:

1. **IP Adresinin Çözümlenmesi (DNS):** Bilgisayar, konuşacağı sunucunun mantıksal adresini bulmak için DNS protokolünü kullanır.
    
2. **Komut İletimi (HTTP):** Bilgisayar, HTTP protokolünü kullanarak web sunucusuna özel komut setleri gönderir.
    
3. **İçeriğin Teslimi ve Render Edilmesi:** Web sunucusu isteği alır, işler ve yanıt olarak HTML, CSS, JavaScript, görseller vb. verileri döner. Tarayıcı da bu verileri görsel bir web sitesine dönüştürür.
    

## 🏗️ 2. Gelişmiş Ağ ve Performans Bileşenleri

### A) Load Balancers (Yük Dengeleyiciler)

Bir web sitesinin trafiği tek bir sunucunun kaldıramayacağı kadar büyüdüğünde veya sistemde **Yüksek Erişilebilirlik (High Availability)** istendiğinde devreye girer. Gelen istekleri ilk karşılayan yerdir ve arkasındaki çoklu sunucu havuzuna trafiği dağıtır.

- **Round-Robin Algoritması:** Gelen her yeni isteği, arkadaki sunuculara sırasıyla (sıra tabanlı) birer birer paslar.
    
- **Weighted (Ağırlıklı) Algoritma:** Sunucuların o an aktif olarak kaç istekle uğraştığını ve mevcut yük durumunu kontrol ederek, trafiği en az meşgul olan veya donanımı en güçlü olan sunucuya yönlendirir.
    
- 🛡️ **Health Check (Sağlık Kontrolü):** Yük dengeleyici, arkasındaki sunucuların hayatta olup olmadığını anlamak için onlara periyodik kontrol istekleri gönderir. Eğer bir sunucu uygun yanıt vermezse veya çökerse, yük dengeleyici o sunucu düzelene kadar ona trafik göndermeyi anında keser (**Failover** mekanizması).
    

### B) CDN (Content Delivery Network - İçerik Dağıtım Ağları)

Ana web sunucusunun üzerindeki trafik yükünü hafifletmek ve site hızını artırmak için mükemmel bir silahtır. Web sitesine ait **Statik Dosyaları** (JavaScript, CSS, görseller, videolar) dünyanın dört bir yanına yayılmış binlerce CDN sunucusunda önbelleğe alır (cache). Kullanıcı bir dosya istediğinde, CDN kullanıcının fiziksel konumuna en yakın sunucuyu tespit eder ve dosyayı oradan gönderir.

### C) Databases (Veritabanları)

Kullanıcı bilgilerinin, içeriklerin ve sistem verilerinin kalıcı olarak saklandığı depolama alanlarıdır. plain-text dosyalardan devasa sunucu kümelerine (clusters) kadar değişebilir. Sektörde en sık karşılaşacağın türler: `MySQL`, `MSSQL`, `PostgreSQL`, `MongoDB`, `GraphQL`.

## 🛡️ 3. WAF (Web Application Firewall - Web Uygulaması Güvenlik Duvarı)

Gelen web istekleri ile ana web sunucusu arasında konumlanan, birincil görevi web sunucusunu hacking girişimlerinden ve servis dışı bırakma (DoS) saldırılarından korumak olan bir güvenlik kalkanıdır.

- **İstek Analizi:** Gelen HTTP isteklerini satır satır analiz ederek yaygın web saldırı tekniklerinin (SQL Injection, XSS vb.) izlerini (signatures) arar.
    
- **Bot Tespiti:** İstek atan kaynağın gerçek bir insan tarayıcısı mı yoksa otomatik bir saldırı botu mu olduğunu doğrular.
    
- **Rate Limiting (Hız Sınırlama):** Belirli bir IP adresinin saniyede gönderebileceği maksimum istek sayısını sınırlandırarak kaba kuvvet (brute-force) ve DDoS denemelerini engeller. Şüpheli görülen paketler sunucuya hiç ulaşmadan WAF seviyesinde düşürülür (drop).
    

## 💻 4. Web Sunucuları Nasıl Çalışır? (Web Servers Architecture)

Web sunucusu, belirli portları dinleyen ve gelen HTTP isteklerine karşılık yerel diskindeki dosyaları istemciye teslim eden bir yazılımdır. En yaygın kullanılan yazılımlar: `Apache`, `Nginx`, `IIS` (Windows) ve `NodeJS`.

### A) Default Root Directory (Varsayılan Kök Dizinler)

Sunucu yazılımları, dışarıya sunacakları dosyaları ayarlarında tanımlanmış olan kök dizinlerden çekerler.

- **Linux (Apache / Nginx):** `/var/www/html`
    
- **Windows (IIS):** `C:\inetpub\wwwroot`
    
- _Örnek:_ Kullanıcı `http://www.example.com/picture.jpg` isteği attığında, Linux tabanlı bir sunucu arka planda kendi sabit diskindeki `/var/www/html/picture.jpg` dosyasını bularak istemciye gönderir.
    

### B) Virtual Hosts (Sanal Konakçılar)

Tek bir fiziksel web sunucusunun, üzerinde farklı alan adlarına (domain) sahip binlerce farklı web sitesini bağımsız olarak barındırmasını sağlayan teknolojidir.

- **Çalışma Mekanizması:** Web sunucu yazılımı, gelen HTTP istek başlıklarındaki (headers) **`Host`** alanını okur. Bu hostname değerini kendi metin tabanlı konfigürasyon dosyalarındaki Virtual Hosts kayıtlarıyla eşleştirir. Eşleşme bulursa o siteye ait diske maplenmiş özel dizini (Örn: `one.com` için `/var/www/website_one`) çağırır. Eşleşme yoksa varsayılan (default) siteyi ekrana getirir.
    

## 🎭 5. Statik ve Dinamik İçerik Ayrımı

### A) Static Content (Statik İçerik)

Kullanıcıdan veya isteğin türünden bağımsız olarak **asla değişmeyen**, sunucudan çıktığı gibi tarayıcıya teslim edilen dosyalardır (Görseller, CSS, JavaScript dosyaları veya sabit HTML sayfaları).

### B) Dynamic Content (Dinamik İçerik)

Gelen isteğe, kullanıcı oturumuna veya girilen parametrelere göre **anlık olarak değişebilen** içeriklerdir (Arama sonuçları, kişisel profil sayfaları, en son blog yazıları).

- **Arka Plan İşleyişi (The Backend):** Bu dinamik değişimler web sitesinin **Backend** (sunucu tarafı) kısmında, programlama ve betik dillerinin (`PHP`, `Python`, `Ruby`, `NodeJS`, `Perl`) veritabanlarıyla konuşması sonucu üretilir.
    
- ⚠️ **Kritik Kural:** İstemci (kullanıcı) **backend kodlarını kesinlikle göremez (Answer: Nay).** Tarayıcıda sağ tıklayıp "View Page Source" denildiğinde görülen HTML kodları, backend dillerinin sunucu tarafında işlenip ürettiği _nihai sonuçtur._ * _PHP Örnek İletişim:_ `index.php?name=adam` isteği atıldığında, arka planda çalışan `<?php echo $_GET["name"]; ?>` kodu sunucuda işlenir ve kullanıcıya sadece temiz bir `Hello adam` HTML çıktısı gönderilir. PHP kodunun kendisi gizli kalır.
    

> 🧬 **Web Server vs. Application Server (Mülakat Bilgisi):**
> 
> - **Web Server:** Sadece statik verileri (resim, text, düz HTML) istemciye iletmekle görevli hafif yazılımdır.
>     
> - **Application Server:** İçerisinde iş mantığı (business logic) barındıran, veritabanı işlemlerini yürüten ve web sunucusunun istemciye vereceği yanıtı dinamik olarak hesaplayan gelişmiş sunucu bileşenidir. Günümüzdeki modern yazılımlar genellikle hibrittir.
>
